# DFR0026 集成说明（MicroPython）

## 1. 接线

| 传感器端 | 官方线色 | 主控端 | 说明 |
|---|---|---|---|
| `S` / Signal | 绿色 | ADC 输入 | 模拟电压，光越强读数通常越大 |
| `+` / VCC | 红色 | 3.3–5 V | 优先选与ADC输入安全范围相匹配的供电 |
| `-` / GND | 黑色 | GND | 必须共地 |

线缆颜色可能因批次或转接线而不同，应优先依据模块丝印和主控接口定义，不可只凭颜色接线。断电完成接线并检查极性后再上电。

## 2. ADC 电压安全

官方资料将模拟输出标为 0–5 V。若主控 ADC 最大输入仅 3.3 V：

1. 不得在 5 V 供电时直接把信号接入 ADC；
2. 可选用经实测确认的 3.3 V 供电，或使用电阻分压/运放缓冲；
3. 分压设计应考虑 ADC 输入阻抗、采样电容和源阻抗；
4. 首次接入前应使用万用表确认最强光照下的输出电压。

## 3. MicroPython API 差异

官方最小示例采用 `ADC(0)` 与 `adc.read()`。不同 MicroPython 端口可能使用：

- `ADC(0)`；
- `ADC(Pin(gpio))`；
- `read()`，常见范围 0–4095；
- `read_u16()`，范围 0–65535；
- ESP32 的 `atten()` 或 `width()` 配置。

因此正式工程必须按板卡 Board Skill 确认 ADC 引脚、构造方式、衰减档位和最大输入电压。

## 4. 采样建议

- 基础交互：100 ms 采样周期。
- 需要稳定显示时：使用 8–16 点移动平均或中值滤波。
- 阈值控制应加入滞回，避免在临界光照下频繁抖动。
- ADC 百分比仅是相对量；不同供电、不同主控和不同安装角度不能直接横向比较。
- 需要 lux 时，应使用标准照度计做多点标定，保存拟合参数和适用光源条件。

## 5. 行空板 K10

官方项目说明将 DFR0026 接到 K10 的 P1 模拟输入，并给出约 0–4095 的读数范围。具体 MicroPython 构造方式仍应以当前 K10 固件和 Board Skill 为准；不要仅根据端口名猜测 `ADC(1)` 一定可用。

## 6. 结构集成

- +X 接线方向预留至少 10 mm 电缆空间。
- 固定孔按 Ø3 mm 设计，建议装配孔留 0.2–0.4 mm 工艺余量。
- 感光器件上方保持无遮挡视场，外壳开孔不能形成深筒遮光。
- 需要方向一致性时，在结构件上标注 +X 接线侧与感光面朝向。
- 紧配结构必须先解决 20 mm 与 22 mm 板宽冲突并实测样品。
