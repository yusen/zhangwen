# 集成说明

## 标准版接口总览

| 接口 | 官方能力 | 集成边界 |
|---|---|---|
| 主供电 Type-C | 5 V / 5 A | 使用独立 25 W 适配器，不用电脑 USB 口供电 |
| 40PIN | 28 个 3.3 V GPIO；SPI、I2C、I2S、PWM、UART | 最大耐压 3.46 V；先检查针脚复用 |
| USB Host | 4 × USB 3.0 Type-A | 官方单接口能力 1 A @ 5 V；多口同时负载需降额 |
| USB Device | 1 × USB 2.0 Type-C | 用于设备模式与维护；本 Skill 不授权烧录 |
| 调试串口 | Micro-USB，115200 8N1，无流控 | 只记录参数，不保存真实主机串口标识 |
| 摄像头 | 2 × 4-lane MIPI CSI-2 v2.1 | 22pin 同向排线；必须断电插拔 |
| 显示 | HDMI 1080p@60fps；4-lane MIPI DSI v1.2 | DSI 供电与排线方向按屏规格核对 |
| 网络 | 千兆以太网/PoE、Wi-Fi 6、Bluetooth 5.4 | PoE 需兼容模块；网络凭据只允许运行时注入 |
| CAN | CAN FD 接口 | 总线两端按需要启用终端电阻并核对线序 |
| 存储 | 1 Gbit NAND、UHS-I microSD | 建议至少 16 GB；运行中禁止热插拔 |
| 音频 | 3.5 mm 输入/输出、HiFi 5 DSP | 核对插头标准、输入输出方向和音量 |

## 40PIN 复用

官方 40PIN 图给出 BOARD、BCM、CVM 与 SoC 编号。`Hobot.GPIO` 支持 BOARD、BCM、CVM、SOC 四种编号，官方推荐 BOARD。RDK X5 的典型复用冲突包括 UART3/I2C5、I2C0/PWM2、SPI2/PWM0、SPI2/PWM1、I2C1/PWM3；使用 `srpi-config` 选择专用功能后需重启，关闭同组专用功能后才能把针脚当普通 GPIO。

RDK X5 提供 8 路硬件 PWM 输出：物理针脚 29、31、37、24、28、27、32、33。官方说明 `Hobot.GPIO` 不实现软件模拟 PWM，X5 的 PWM 支持范围为 0.05 Hz 至 1 MHz；默认启用 PWM3，其他组需按官方配置启用。

## RDK OS 与软件

- 官方下载页说明，RDK X5 系统镜像 3.0.0 及以上基于 Ubuntu 22.04，低于 3.0.0 的版本基于 Ubuntu 20.04。
- RDK OS 自带 `Hobot.GPIO` Python 库；导入后可读取 `GPIO.model` 确认目标为 `RDK_X5`。
- 40PIN 示例使用 BOARD 物理针脚编号并在结束时调用 `GPIO.cleanup()`。
- Python 多媒体与 AI 接口、TogetheROS、Model Zoo 受系统镜像和软件包版本影响，部署前按当前官方文档核对。
- 本 Skill 不包含镜像下载、Flash 擦除、烧录、分区或上传命令，也不授予这些操作权限。

## 推荐接入流程

1. 断电确认板卡丝印为标准版 RDK X5，检查适配器为稳定 5 V / 5 A。
2. 查官方 40PIN 图，确认物理针脚、电源、地、信号方向和复用关系。
3. 先只接一个低功耗 3.3 V 外设；共地后再接信号，最后接电源。
4. 上电后先确认电源灯和系统状态，再在 Python 中读取 `GPIO.model`。
5. 逐一验证 GPIO、PWM 或总线；多接口同时工作前进行电流、压降和散热复核。
6. 摄像头、TF 卡、DSI 排线、CAN 线缆或天线需要更换时，完全关机并断开主电源。

## 板卡差异

- 标准版 RDK X5 为全板载设计；RDK X5 Module 是核心模组加 IO 载板，接口编号、调试串口速率、电平选择和连接器不同。
- 标准版 40PIN 固定为 3.3 V IO；Module 载板的 IO 电平选择能力不能套用到标准版。
- 4 GB 与 8 GB 型号的内存不同，其余能力仍需按具体硬件版本、系统镜像和官方变更记录核对。

## 故障排查

- 反复重启：优先检查是否误用电脑 USB 供电、适配器和线缆压降是否满足 5 V / 5 A。
- GPIO 无响应：确认 BOARD 针脚编号、`GPIO.model`、复用配置和重启是否完成。
- PWM 无输出：确认所选物理针脚属于已启用的硬件 PWM 组，且频率在官方范围内。
- I2C/SPI/UART 冲突：检查同组复用功能是否同时启用，核对外设电平、上拉和线序。
- 相机不识别：断电后复核 22pin 排线方向、接口选择与官方适配型号；禁止通电重插。
- USB 外设掉线：降低单口和总负载，检查 25 W 适配器、线缆和板温。
