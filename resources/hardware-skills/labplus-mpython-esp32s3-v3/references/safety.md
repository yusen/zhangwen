# 安全边界

## 禁止操作

- 禁止把 5V 接入 3V3 金手指或任一 3.3V GPIO/ADC/总线信号。
- 禁止 USB 供电时再从外部向 3V3 引脚强制供电，避免电源互相反灌。
- 禁止用 GPIO 直接驱动电机、舵机、继电器、灯带或其他大电流/感性负载。
- 禁止带电插拔裸线、短接金手指或在金属表面直接放置通电板卡。

## 电流与热风险

- 官方最大工作电流为 700mA、最大负载电流为 1000mA；这不等于任意 GPIO 或 3V3 引脚都可提供该电流。
- 外接负载应使用独立受保护电源，按需要共地，并核算启动/堵转/峰值电流、稳压器温升和线缆压降。
- 喇叭和功放长时间大音量工作可能产生温升和听力风险。

## 接线顺序

1. 断开 USB 和外部电源，确认电压、极性、接口方向和共地方案。
2. 先接 GND，再接信号，最后接合规电源；拆除时反序。
3. 首次上电使用限流电源或受保护 USB 供电，观察异常发热、气味和反复复位。

## 环境与机械

- 板卡不具备本文档声明之外的防水、防尘、抗冲击或绝缘等级。
- 保护 LCD、麦克风、喇叭和 USB 接口，避免按压、液体、静电与线缆侧向拉力。
- 包络模型没有孔位、开孔和避让区，不能直接用于量产外壳。
