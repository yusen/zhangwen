# 安全边界

## 禁止操作

- 禁止带电插拔或在未确认 `+`、`-`、`D` 顺序时上电。
- 禁止把 SEN0388 的电源、地和数字信号接反。
- 禁止把 5V 数字信号直接输入 K10 P1；本包默认使用 3.3V 同源供电。
- 禁止把 `D` 当作模拟量输出并生成 `read_analog()` 或 ADC 换算代码。
- 禁止按压、碰撞、进液或用胶体覆盖开放式超声波探头表面。
- 禁止把单次超声读数作为人身安全、急停或唯一防撞依据。

## 推荐措施

1. 断电完成接线并核对丝印，确认模块 SKU 为 SEN0388。
2. 优先使用 K10 P1 Gravity 端口的 3.3V、GND 和 Signal。
3. 使用同一个 P1 完成触发和回波测量，循环间隔不短于 40ms。
4. 首次上电只打印距离，在 30cm、50cm、100cm 处用平整挡板核对。
5. 外壳保护 PCB 和接线座，同时让两个探头正面完全无遮挡。

## 电气与环境边界

- 官方工作范围为 3.3–5.5V，最大瞬时电流小于 20mA；K10 默认方案采用 3.3V。
- 官方工作温度为 -10–70℃。凝露、雨水、腐蚀、导电粉尘环境不在本包验证范围内。
- 超声测量受目标材质、角度、面积、空气流动、温度和多径反射影响。
- 多个超声模块同时工作可能互相串扰，应错开触发时间并实测。

## 机械风险

- 官方只确认模块外形约 47×22mm；本包孔位、接线座和探头包络仍需对照 SEN0388 实物复核。
- 开孔必须保留两个探头的声学视场，避免壳体边缘形成反射或遮挡。
- 尚未完成反接、过压、ESD、跌落、防水、温循和长期运行验证。
