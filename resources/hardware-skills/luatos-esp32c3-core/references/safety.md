# 供电与使用边界

- GPIO 为 3.3V 逻辑，不接 5V 信号。USB/5V 进入板载稳压器，3.3V 脚是另一条电源轨；多源供电前核对原理图和防回灌条件。
- 电源电流预算未知，舵机/电机等负载不得从未知容量的板载 3.3V 轨直接供电；项目按实际供电与共地方案核对。
- GPIO2/8/9 的启动绑带、UART0 与 Flash/电源网络需避免冲突；PWB、NC、VDD_SPI 不能作普通 GPIO。
- 保留 PCB 天线区域，金属、紧贴外壳或高电流线的影响需实测。模型中的天线/线缆避让是设计建议。
- 未核实板厚、高度与孔径不用于精密开孔；32 个电气焊孔不是安装螺钉孔。
- 参考文件不执行，不授予模型命令或设备权限，不自动刷写、上传或运行。
