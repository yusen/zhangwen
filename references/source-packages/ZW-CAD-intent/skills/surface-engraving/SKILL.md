# 模型表面凹刻

## 职责

把用户自由表达的自然语言转换为完整的刻字状态和受限 CadQuery 补丁。只处理已有模型；盒体、硬件、开孔、布局和确定性模板主体仍由原程序生成。

本 skill 是 CadQuery 平面刻字能力与安全边界，不是要求用户逐项填写的参数表。`target_part`、锚点、法向量、参考点、局部方向和字号等是 agent 最终需要解析或推导的内部状态，不得把内部字段名直接抛给用户。

## 理解自然语言

1. 同时阅读当前未刻字源码、已有刻字、待完成草稿和最近相关对话，再判断本轮意图。
2. 允许用户在同一句中提供多个信息，也允许倒装、省略、口语、毫米单位简称、相对位置和多轮修正。例如“右边正中写上 ZW-CAD，高 15 毫米”和“在右侧面中央刻字，内容 ZW-CAD，字高 15mm”表达相同意图。
3. 新的明确内容与位置描述默认新增刻字；出现“改、换、调整”等语义时更新匹配刻字。新明确值覆盖旧值，本轮未提及的值继承草稿或原刻字。
4. 待完成草稿正在等待字号时，单独回复“15mm”要绑定为字号；“改成 8mm”只更新字号。“改成两行”要继承原文字和位置并生成多行排版，不要求用户重述。
5. 缺少平面内位置时默认正中央，偏移为 0；缺少旋转时使用目标面的标准正向排版。
6. 缺少字号时，由后端根据目标面和文字预检安全推断：不超过 `8mm`，约取可容纳高度的 70%，向下取到 `0.5mm`，且不得低于 `3mm`。在结果摘要中说明实际采用的字号。
7. 用户明确给出的字号必须保持精确；若放不下，只返回可容纳的建议字号并等待确认，不得静默缩小、裁切或改写文字。
8. 只有存在会影响结果的重要歧义时才追问，例如目标外部平面无法唯一确定，或多条已有刻字都可能是修改目标。不要重复询问已经识别或可以安全推导的信息。

面向用户始终用自然中文说明已识别内容、推断结果、能力边界和需要补充的信息，但绝不要求用户“用中文输入”，也不要求用户提供英文枚举、法向量、坐标或代码字段。

## 文字与排版边界

- 只支持凹刻。单行最多 32 个 Unicode 字符；多行总计最多 256 个字符、最多 32 行，且每行仍不超过 32 个字符。最小字体高度为 `3mm`，刻字深度固定为 `0.6mm`。
- 支持真实换行、“第一行/第二行”、“两行/多行/分两排”和指定行数。拒绝空行及其他控制字符；引号、反斜杠及常用中英文符号必须正确转义。
- `text` 保存完整逻辑文字，`lines[]` 保存实际行内容，`layout_mode` 为 `single_line` 或 `multiline`，默认 `line_spacing_ratio=1.2`。
- 用户明确换行或指定行数时执行。用户未明确要求时保持单行；仅在单行接近目标面可用宽度时，才允许后端根据预检建议自动换行。
- 用户只说“改成两行”时，把当前文字尽量均匀分行；若用户指定每行内容，严格保留其分行。不得要求用户重复平面、位置或字号。
- 请求曲面、内部面或凸字时，明确说明当前不支持，并请用户改选可识别的外部平面或凹刻方式。

## 草稿与增改删

使用 `surface_engraving_draft_v1` 在多轮间保留部分结果。草稿包含 `schema_version`、`draft_id`、`task_id`、`pending_operations`、`surface_engravings`、`provided_fields`、`inferred_fields`、`missing_fields`、`user_turns`、`requested_layout` 和可选的 `original_feature_conflict_confirmation`。这些都是后端内部状态，不是用户必填项。最终刻字状态可升级为包含 `lines[]` 的多行结构，但旧单行状态必须按 `lines: [text]` 兼容读取。

`original_feature_conflict_confirmation` 只能由服务器在真实 CadQuery 预检返回 `engraving_original_feature_conflict` 后创建，凭据版本固定为 `surface_engraving_original_feature_confirmation_v1`，并同时保存本次已规范化、实际失败的完整 `surface_engravings`。凭据包含 `task_id`、未刻字源码 `source_hash`、完整刻字状态 `spec_hash`、`engraving_id`、`surface_id` 和精简交集数据 `conflict`。LLM 输出不得创建、改写或猜测该凭据。

- “再刻一条”生成新的稳定 ID，并追加。
- “把上盖这条文字改成……”更新唯一匹配的已有 ID，未重新说明的属性继续沿用。
- “删除右侧刻字”删除唯一匹配项；“删除全部刻字”清空列表并移除补丁。
- 重复提交同一完整请求时，按稳定 ID 更新或判定无变化，不得重复新增或重复切除。
- 成功、新项目、明确取消刻字或切换到无关任务后清除草稿；需要补充或能力阻断时保留草稿、原 artifact、源码和预览。
- 只有用户在上一轮有效冲突后明确回复“确认强制刻字”、“忽略冲突继续刻字”或“无视影响直接刻字”等同义表达时，才可尝试强制分支；含糊的“继续”不算确认，首轮直接要求绕过也不生效。
- 确认时使用草稿保存的完整 `surface_engravings` 确定性复检，不重新请求 LLM。只有任务 ID、源码哈希、完整参数哈希、失败刻字 ID 和目标面全部一致时才可写入 `allow_original_feature_intersection: true`。任一字段变化后覆盖立即失效，必须重新预检和确认。

## 平面与内部坐标

根据模型源码把“上盖外表面、底面、前后左右侧面、斜面正面”等自然语言定位为：

- `target_part`：`base_part` 或 `lid_part`；
- `normal_hint`：目标平面的外法向量；
- `point_hint`：目标平面附近的世界坐标参考点；
- `x_direction`：文字横向在平面内的方向，局部 `v = normal × u`；
- `anchor` 与毫米偏移：局部 `u` 向右、局部 `v` 向上。

helper 支持左上、上方中央、右上、左侧中央、正中央、右侧中央、左下、下方中央、右下九个锚点。agent 应从用户的自然描述映射这些内部值；无法唯一判断且会改变结果时，才用自然语言询问具体位置。

通用盒体可定位上盖、底面及前后左右外表面；确定性模板还可定位能够可靠识别的外部斜平面。不得选择曲面、内部面或无法由法向量与参考点唯一确定的平面。

同一法向存在多个斜面时，按“法向匹配、参考点到平面距离、参考点投影是否落在真实裁剪面、局部外向可见性、稳定面积/跨度签名、面积、面中心距离”的顺序选择。不得再要求目标面位于整个实体沿法向的全局最外层，因为凸出的卡槽不能排除后方仍然暴露的主斜面。仅说“斜面”时，最大候选面积至少为第二候选两倍可自动选择最大主斜面；否则用中文列出候选面追问。

每个目标零件必须保留未刻字参考实体：所有刻字都在参考实体上解析表面和边界，再在累计实体上依次切除。这样第二条文字不会选中第一条刻字产生的微小平面残片。预检要区分原始面太小、切除体为空、与原模型零交集、原模型开孔或边界冲突、已有刻字重叠和稳定表面身份不匹配，并在报告中写入候选数量、选择原因、面积、局部跨度、参考点到平面距离和选面器版本。

`allow_original_feature_intersection: true` 只能放行“切除体有效、与未刻字参考实体有非零交集，但交集率因边界或原有孔位低于安全阈值”这一类冲突。切除体为空、零/无效交集、已有刻字重叠、无效目标面、字体错误和源码安全检查失败仍必须阻断。
其中切除体为空/体积过小返回 `engraving_invalid_cutter`，与原模型完全没有有效交集返回 `engraving_no_intersection`；这两类错误不属于可强制覆盖的 `engraving_original_feature_conflict`。

## 受限代码契约

只允许生成以下两个 Python 语句，不得重写原模型：

```python
surface_engraving_specs = [...]
base_part, lid_part = apply_surface_engraving_patch(base_part, lid_part, surface_engraving_specs)
```

补丁只能包含刻字参数字面量和固定 helper 调用，只能更新 `base_part`、`lid_part`。`surface_engraving_v2` 允许服务器追加可选的 `allow_original_feature_intersection` 和 64 位 `original_feature_intersection_source_hash`；其他来源不得声明或伪造这两个字段。AST 白名单必须拒绝 import、函数或类定义、文件读写、网络、系统调用、动态执行、任意 Python 表达式，以及对硬件、盒体参数或主体几何的修改。结构化 operations、最终 specs 与补丁必须一致。

完整 helper 位于 [references/cadquery-planar-engraving.py](references/cadquery-planar-engraving.py)，负责：

- 选择与法向量、参考点匹配的最大外部平面；
- 建立局部坐标和九宫格锚点；
- 加载可用的中英文字体；缺少中文字体时明确阻断中文刻字；
- 把多行作为一个文字块计算宽高、行距和锚点，并检查是否完全落在目标面内、是否碰到边界、开孔或螺丝孔；
- 沿外法向反向切除 `0.6mm`，并生成包含切除体体积、参考/当前交集体积与交集比例的预检报告；
- 强制覆盖生效时，在该条报告写入 `original_feature_intersection_override` 和 `warnings[]`，其中明确标记“文字可能被边界裁断或影响孔位”，不得冒充普通安全通过。

注入新补丁前，必须用开始/结束标记移除旧刻字区块，再根据完整刻字状态重新注入，避免重复切除。

## 输出与验证

输出结构化增改删 operations、完整 `surface_engravings`、受限补丁、草稿或清除状态、预检结果、建议字号和用户可读摘要。多行状态中 `text` 保存包含换行的完整逻辑文字，`lines[]` 保存实际分行；旧单行消费者读取 `lines[0]` 即可。强制刻字结果还必须向前端传递 `original_feature_intersection_override`、`warnings[]`、`reference_intersection_ratio` 和 `intersection_ratio`，供确认状态和校验区持续显示风险。

如果最新输入明确是在做圆角、倒角、开孔、厚度或硬件位置等结构修改，返回内部 `not_applicable`，由总 Agent 同一轮最多重路由一次到 `model_edit`；不得重新预检旧刻字草稿，也不得让刻字 helper 越权修改主体结构。

按以下顺序验证：

1. 校验文字、分行、长度、字号、稳定 ID、目标零件和平面内部状态。
2. 校验 operations、完整 specs 与补丁一致，并通过 AST 白名单。
3. 运行 CadQuery 外部平面、边界、孔洞相交、字体和字号预检。
4. 构建真实 STEP/STL，检查实体体积发生合理减法变化、包围盒正常并通过 mesh 校验。
