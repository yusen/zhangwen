# 固件烧录、Thonny 与部署

## 官方提供的两种固件准备方式

### 方式一：Mind+ V2

- 选择 MicroPython 积木模式；
- 安装 0.0.5 或以上版本的行空板 K10 扩展；
- 按软件流程连接和烧录。

### 方式二：ESP32 固件烧录工具

- 下载 K10 MicroPython 固件；
- 使用 ESP32 固件烧录工具；
- 芯片选择 ESP32-S3；
- 按住 K10 背面 BOOT 键再连接数据线；
- 识别串口后先 ERASE，再 START；
- 完成后按 RST。

具体分区地址应以固件压缩包内的官方说明或页面截图为准，不得由智能体猜测。

## Thonny

1. 安装 Thonny。
2. 解释器选择 ESP32/MicroPython。
3. 新建程序。
4. 保存时选择 MicroPython 设备。
5. 文件名使用：

```text
main.py
```

6. 点击运行。
7. 查看 Shell 中的串口输出。

## 保存位置

- 保存到电脑：适合编辑和备份，但不会自动成为设备开机程序。
- 保存到 MicroPython 设备：文件才存在板内。
- 保存为 `main.py`：通常用于复位或上电后运行。

## 常见连接问题

- USB 线必须支持数据传输；
- 串口不能被其他软件占用；
- Windows 10/11 通常无需额外驱动；
- 无法识别时先更换官方数据线、USB 口并避免扩展坞；
- Windows 7 可能需要安装驱动；
- BOOT/RST 操作要按照烧录步骤执行。
