# ZW-CLOSURE-001 — 两阶段产品闭环与原始 P0 收口

状态：软件实现与自动验收完成，外部验收待办（2026-07-26）。

## 目标

在不破坏中央永久主对话、固定“工作 / 产物 / 设备”三 Tab、本地受控执行和设备安全边界的前提下，完成两阶段交付：

1. 第一阶段形成可发布软件闭环：邮箱账号、账号级本地项目隔离、统一项目进度、简化计划确认、自动浇花硬件/代码/设备模拟闭环。
2. 第二阶段收口仍保留的原始 P0：项目复制与回收区、结构化 MicroPython 项目、真实最小硬件目录、无障碍、文案分层、启动性能和发布验收。

真实 SMTP、真实 DeepSeek、真实 K10/SEN0193/DFR0523 与公开部署属于外部验收门槛；资源未提供时只能记录“软件完成、外部验证待办”。

## 产品决定

- 身份：新增独立、自建 FastAPI 云端身份服务；邮箱验证后才能使用，不恢复游客模式。
- 数据：项目、对话、产物和设备记录仍保存在本机，但按云端账号 `subject` 严格隔离，不做跨设备项目同步。
- 离线：最近一次云端验证成功后，可信设备可离线使用 30 天；云端长期令牌不进入 React 或项目数据库。
- 画像：教师/学生/工程师/创客/其他、技术水平、常用板卡、预算倾向和教学需求进入账号资料，只影响推荐上下文，不改变权限。
- 首个硬件闭环：K10 + SEN0193 + DFR0523 + 外接稳压 5V/3A 电源；泵不得从 GPIO 或 K10 板载供电。
- 普通模式：自动选择专家，只显示用户语言；专业模式才允许调整专家和查看内部工程详情。
- 正式工程：立项书确认后显示中央简化执行摘要，工程规格、代码、测试、部署必选，CAD/教案可选。
