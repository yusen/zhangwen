# ZW-AUTH-001 — 本机账号注册、登录与平台门禁

状态：实现完成且自动与隔离 UI 验收通过（2026-07-15，真人桌面抽检待用户，未提交）

## 1. 目标

1. 未登录时只显示掌问注册/登录界面，不挂载项目工作台。
2. 支持本机用户名、显示名称和密码注册；注册成功即建立会话。
3. 支持登录、持久会话恢复、会话失效回到登录页和显式退出登录。
4. Sidecar 对除健康检查和认证入口外的全部 `/api` 业务请求强制验证 Bearer 会话，不能只做前端遮罩。

## 2. 范围与保守默认值

- 当前仓库没有云端身份服务，产品是本地优先桌面应用。本任务实现设备本地账号与访问门禁，不虚构邮箱、
  短信、验证码、找回密码、跨设备同步或远程账号。
- 账号数据保存在独立 `<data_dir>/auth/zhangwen-auth.sqlite3`，不提高项目数据库 schema 版本，也不把
  密码、会话令牌或账号私密字段写入项目包、聊天、日志或 LLM 上下文。
- 本任务只要求登录后才能使用当前本机平台，不把既有项目按账号隔离。多账号登录后仍访问同一台设备的
  当前项目库；真正的多租户/云同步必须另立数据归属迁移。
- 不修改 `CURRENT_TASK.md`，不覆盖并行 ZW-AGENT/ZW-HW/ZW-LLM/ZW-UX/CAD/安装包改动，不创建 ZW-017。

## 3. 安全契约

- 用户名为 3-32 位 ASCII 字母、数字、点、下划线或短横线，并按不区分大小写唯一；显示名称允许中文。
- 密码为 8-128 字符，至少包含一个字母和一个数字。服务端使用随机盐与 PBKDF2-HMAC-SHA256 派生，
  只保存盐、派生值和迭代次数，比较使用恒定时间函数。
- 会话令牌使用加密安全随机数；数据库只保存 SHA-256 摘要。会话默认 30 天到期，退出后服务端撤销。
- 认证失败统一返回稳定中文信息，不暴露账号是否存在、密码摘要、盐、令牌或数据库细节。
- `GET /api/health`、`GET /api/health/desktop-capability`、`GET /api/auth/status`、
  `POST /api/auth/register`、`POST /api/auth/login` 为公开入口；其余 `/api` 请求必须带有效 Bearer token。
- 自动测试可显式设置 `ZHANGWEN_AUTH_DISABLED=1` 隔离旧业务回归；生产默认始终启用，认证专项测试不得
  使用该旁路。

## 4. 接口与 UI

- `GET /api/auth/status` → `{ hasAccounts }`。
- `POST /api/auth/register` → `{ account, sessionToken, expiresAt }`。
- `POST /api/auth/login` → `{ account, sessionToken, expiresAt }`。
- `GET /api/auth/session` → `{ account, expiresAt }`。
- `POST /api/auth/logout` → `{ loggedOut: true }`。
- 桌面启动先检查会话。无账号时默认注册；已有账号时默认登录。认证成功后才挂载 `AppShell`。
- 顶栏显示当前显示名称并提供“退出登录”；退出或任意业务 API 返回 401 时卸载工作台并回到登录页。

## 8. 已知限制与真人抽检

- 当前是设备本地访问门禁，不含邮箱验证、找回密码、跨设备同步、云端身份或账号管理后台。
- 当前项目库不按账号隔离；这台设备的多个本机账号会看到同一项目库。若要账号级项目归属，必须另立迁移。
- 真人抽检：启动当前 Tauri 桌面，创建或登录本机账号，确认进入项目工作台；退出后确认不能访问项目；
  重新登录确认项目恢复。不得为抽检调用真实付费 LLM、串口、上传、Flash 擦除或固件烧录。
