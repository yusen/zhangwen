# ZW-UX-006 - 原型视觉系统渐进迁移

状态：实现完成，自动验收通过（M1-M15），真人桌面串口验收待用户（未提交）

## 1. 目标

在不重写 `AppShell`、不引入原型假数据模型、不改变现有 API/领域状态机的前提下，
把 `ZW_V1_FullApp_Prototype.html` 中可复用的视觉 token、卡片层级和状态表达渐进迁移到
现有 React 组件。第一批以全局 token 和现有 class 的代表性壳层、中央结构化卡片、右侧卡片
和浮窗为范围；DOM、数据请求、事件处理和领域状态保持不变。

## 2. 不可变边界

- 中央区域仍是唯一项目主对话；`CenterChat` 在工作区生命周期内只挂载一次。
- 右侧一级 Tab 仍固定为“工作 / 产物 / 设备”，不新增页面或平行工作台。
- 保留现有 `ProjectWorkspace`、API、shared contracts、中央确认流、浮窗管理和设备安全门禁。
- 保留 UI Contract 的 48px 顶栏、240px 左栏、320px 右栏与现有响应式覆盖层规则。
- 不引入 CDN 字体、暗色主题、第三方 UI 框架、全局状态库或原型的 `innerHTML`/全局 `S` 模型。
- 普通模式继续隐藏 Agent、Skill、工具链、内部 ID、高级设备信息和具体模型参数；仅显示供应商无关的模型服务摘要、安全凭据状态/入口与连接状态。服务商、Base URL、精确模型、思考模式和请求超时仅专业模式可见。
- 不编辑或覆盖并行的 `ZW-UX-003`、`ZW-UX-005`、`ZW-AGENT-006`、`ZW-PKG-001`
  与 `ZW-CAD-001` 业务实现；共享 `App.css` 只做小块可审计补丁。
- 不操作真实串口、设备上传、设备重启、Flash 擦除或固件烧录。

## 3. 第一批可观察验收

- `:root` 提供完整的背景、表面、边框、正文、弱文字、品牌、专家、成功/警告/危险/信息、
  圆角、阴影和动效 token；现有未定义颜色变量全部有确定值。
- 顶栏、左右栏、中央输入区、右侧 Tab 和浮窗使用一致的层级、边框、阴影与焦点样式，
  但布局尺寸和 DOM 所有权不变。
- 澄清卡、方案卡、代码/CAD 卡、中央确认卡、工作摘要、产物卡和设备分区形成明确主次层级；
  页面区块不被改造成新的嵌套导航或路由。
- 状态颜色只作为辅助；所有主要状态继续显示中文文本，并为成功、进行中/待确认、失败/阻塞、
  普通信息提供一致色调。
- 当前工作树已有的确认后右栏 `refreshRevision` 刷新行为继续通过既有回归，不由本任务重写。
- `1280x720` 保持 48/240/320 三栏；`720x720` 和 `390x844` 保持覆盖层、固定三 Tab、
  单一 `main`，无页面级横向溢出或主要操作重叠。
