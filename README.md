# 掌问 · 造物智能体

## 掌问是什么

掌问是一个**本地部署的开源造物智能体平台**——你带着手里已有的主控和模块进来，一步一步与掌问确认就可以把想法变成现实。

掌问为做中学而生。

它不是一句话替你全做完，而是一步一个确认：

1. **选主控、加模块**：平台按「这块主控 + 这个模块」给出接线方式、信号脚、电平对不对——不靠翻手册猜。
2. **先联调，再写功能**：先生成一个最小测试程序，只读数，验证接线和模块本身。
3. **读数对了，再一步一步加功能**：每一步 AI 给出的都是候选，你看过、改过、确认后才进入项目。
4. **最后成形**：程序、外壳 STEP/STL、激光切割 SVG/DXF，都存在同一个项目档案里。

**它有什么不同：**

- **打通各厂家的模块**：你手里有一块主控、几枚不同厂家的传感器，在掌问里都能配起来用——不被某一家软件的生态绑定。
- **懂硬件的 AI**：内置本地器件资料库，收录 5 款主控、253 个模块，记清引脚、电平、时序与联调状态——AI 写代码前先查资料，不靠猜。
- **全流程碰得到硬件**：浏览器直连掌控板 / ESP32 / K10，上传、SHA 回读、运行、终端一体完成。
- **本地部署、免登录**：服务只监听 `127.0.0.1`，API Key 只存本机；课堂开机即用，数据不出校门。

## 为什么做掌问：造物路上有三道槛

### 槛一：各家软件，各认各的模块

手里有主控、有传感器，是创客的常态；难的是把它们凑到一起。

同样测一个距离——DFRobot SEN0307 是模拟量，先得确认 ADC 与换算公式；Grove 是单线脉冲，一脚收发，时序完全不同；乐动走 I²C，还要配库和固件；HC-SR04+ 是双线脉冲，接线和电平都得重核。板子没错、模块也没错，凑在一起就是不动。

很多图形化软件主要服务自家硬件生态，跨品牌的组合没人管。**开源硬件的「开源」，不该停在各家围墙里。**

### 槛二：AI 越顺，问题越大

大模型让写代码从「记语法」变成「说人话」，但学生用 AI 写科创程序常是一问即得：代码复制进编辑器就能跑，中间没有「待验证」这一步。方案是谁给的、参数为什么这样取、出了错该查哪一环，学生往往说不清；教师一节课面对几十个小组，根本顾不过来。

### 槛三：顺序反了，时间不站在你这边

多数人先写代码、再插线、然后一起调。一句「读不到数据」，可能是引脚写错、电平不匹配，也可能是模块坏了——说不清是谁的错，新手就卡在这里。传统流程八步、周期按周算，一次失败可能吃掉一个学期。

## 掌问怎么解

### 先接线，再写代码

顺序一倒，新手就不再卡在「到底是谁错了」：

1. 选主控、选模块，把线接好
2. 平台按「这块主控 + 这个模块」告诉你信号脚接哪里、电平对不对
3. 先生成一个最小测试程序——只读数，不做别的
4. 读数对了，再往上加功能

读不到数，问题就在接线或模块；读到了，才轮到写功能。**一个说不清的黑盒，拆成两个能分别验证的步骤。**

### 一个主控，接不同厂家的模块

5 款主控、253 个模块档案，跨品牌挑选；换模块、换主控时，平台按新组合重新适配引脚、接口和代码，不用从零重来。协议、电平、驱动库仍要按实物核对——平台负责把信息摆到你面前，验还得你自己验。

这不是愿景，是已经做过的事：同一枚盛思 I²C 超声波，从掌控板 2.0 换到掌控板 3.0、再换到行空板 K10，平台逐板给出接线与最小联调程序；DFRobot 的 LM35、Grove 的超声波、N+ 的舵机，也都在掌控板上逐一跑通。

### 一条验证链，管住 AI 的「太顺」

生成结果不能直接当答案，程序必须走完五步：

```
候选 → 采用 → 上传 → 回读 → 实机测试
```

先生成候选，学生看过才采用；上传后回读版本、与预期比对；最后用测试用例确认功能。**版本一致只说明「程序版本符合预期」，不等于功能与安全都通过**——出了异常，回到资料、接线、程序、供电逐个排查。

这条链同时划出人机分工线：器件检索、代码生成、结构出图交给 AI；**问题界定、参数取值、异常归因留给学生。** 判断权不能外包——这是整套平台成立的前提。

### 三个角色，各管一段

把硬件选型、写代码、做结构混在一次对话里，结果往往是代码能跑，课没上成。掌问把 AI 按三段切开，各管一段、各有分寸：

| 角色        | 管什么       | 产出                          | 状态                  |
| --------- | --------- | --------------------------- | ------------------- |
| **学习设计师** | 目标、任务与评价  | 项目定义卡、探究活动、评价量规             | 界面与材料预览已就位，追问暂由教师承担 |
| **智能工程师** | 硬件、程序与调试  | 器件检索与选型、候选程序、上传与回读          | 已用于日常教学             |
| **结构设计师** | 尺寸、模型与加工图 | 参数化外壳 STEP/STL、激光切割 SVG/DXF | 已用于日常教学             |

三个角色围绕同一个项目档案协作，只共享已经确认的事实，没确认的单稿不进项目。每一步都由人来确认，实物也由人来实测。

### 结构也在一起

不用再单独学 CAD：参数化 3D 直接出 STEP / STL，激光切割出毫米级 SVG / DXF，和代码、器件清单一并存进同一个项目。

## 开发者背景

来自一线基础教育工作者，专业从事创客教育与STEM教育研究，是中国创客教育探索者。2012 年从一块 Arduino 开始带学生玩开源与创客；2018 年联合发起国内首款开源教育硬件「掌控板」，如今它已是国内主流教育开源硬件；2020 年人教社与中国地图出版社出版的高中信息技术教材《开源硬件项目设计》，我担任本册主编。

十几年下来，其实一直在做同一件事：让更多学生参与造物，让门槛更低，目的就是把想法变成现实。大模型把这件事推到了新高度——用自然语言实现造物。

## 适合谁

- **家庭造物**：没有工科背景的家长，可以和孩子把想法真正做出来，而不是照着图纸拼一套只会拼一次的套件。
- **学校老师**：非技术背景的教师也能独立开出造物课，不必等信息技术老师有空。
- **开发者**：把驱动移植、引脚核对、外壳建模这些重复劳动交出去，精力留给真正的功能。

## 一条命令安装并启动

Windows 10/11 x64，**CMD、Windows PowerShell 和 PowerShell 7 均执行同一条命令**。首次安装与覆盖重装通用：

```cmd
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -Command "[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; & ([scriptblock]::Create([Text.Encoding]::UTF8.GetString([Net.WebClient]::new().DownloadData('https://gitee.com/zmh1979/ask-with-your-palm/raw/master/install.ps1')))) -Reinstall"
```

首次安装创建程序和桌面入口；再次执行会下载并覆盖同一安装位置的程序，保留项目、对话和 API 设置。重装前先保存项目，在原服务窗口按 Ctrl+C；自定义安装过路径的用户须继续指定原 `-InstallDir`，见[部署指南](docs/DEPLOYMENT.md)。

macOS 13.5+，Apple Silicon / Intel，在终端执行：

```bash
curl -fsSL https://gitee.com/zmh1979/ask-with-your-palm/raw/master/install.sh | bash
```

无需预装 Git、Node.js 或 Python，无需先下载仓库。先检测已有环境，缺失才准备项目内运行时；依赖按锁定版本检查、补齐，随后构建并打开浏览器。默认 <http://127.0.0.1:30801> ，端口不可用时自动切换到空闲端口，实际地址显示在服务窗口。首次安装需要联网。

Windows 自动创建桌面 **ZhangWen** 启动图标（掌问手掌 Logo），以后双击即可。macOS 自动创建带掌问 Logo 的 **掌问.app**，优先放入可写的 `/Applications`，否则放入个人 `~/Applications`；可从 Finder 打开或固定到 Dock。首次点击在终端启动本地服务并打开浏览器；关闭网页后再次打开同一个掌问.app，会重开原服务页面，连续点击不会重复开终端。原 `~/Library/Application Support/ZhangWen/启动掌问.command` 也可继续使用。保留服务窗口，Ctrl+C 停止服务。使用桌面 Chrome / Edge 进行 Web Serial 和本地项目文件夹操作；Safari 不支持 Web Serial。

macOS 找不到入口时，无需卸载或重启电脑：先在 Finder 按 `⌘⇧G` 分别查看 `/Applications` 与 `~/Applications`。从旧版平台内更新可能使用旧安装器，遗漏新增入口；新版本正常启动时会尝试补齐。也可先保存项目、在原服务终端按 `Ctrl+C`，再重跑上方安装命令，依赖完整时会复用，用户数据保留。安装输出中的 `Application:` 是实际入口路径；安装失败时先查看错误，不要删除 `data`。

再次执行安装命令检查并安装 Gitee 最新版本；Windows 命令带 `-Reinstall`，同一版本也重新下载、校验和替换程序，环境准备失败时恢复原目录；macOS 同版本校验通过后复用。每日启动使用图标/本地启动文件。平台支持启动检查和手动「检查更新」，显示当前及线上发布版本号（如 `V0.4.2026.1020.01`，V0.4 + 日期 + 当天发布次数），当前编号见 [version.json](version.json)。确认后才安装，下次启动生效；检查失败不影响现有工作台。新版本准备成功才切换入口，旧版本和用户数据保留。

Windows 安装、启动和后台更新会隔离当前进程的 PowerShell 模块路径，避免 PowerShell 7 / 自动化环境与系统 Windows PowerShell 5.1 混用。旧版更新出现 `Get-FileHash` 加载失败时，见[部署指南中的恢复步骤](docs/DEPLOYMENT.md#windows-powershell-模块冲突)。

国内入口的源码、更新与首次安装依赖均使用国内下载源；用户数据与程序版本分开保存。旧版 Windows 桌面版保留于原 Git 历史与 `v0.1.1` / `v0.1.3` 标签，新版不自动迁移旧桌面数据。下载来源、切换渠道及验证边界见 [国内安装说明](docs/DOMESTIC_INSTALLATION.md)。

## 使用 GitHub 下载源

Windows CMD / PowerShell：

```cmd
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -Command "[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; & ([scriptblock]::Create([Text.Encoding]::UTF8.GetString([Net.WebClient]::new().DownloadData('https://raw.githubusercontent.com/yusen/zhangwen/main/install.ps1')))) -Reinstall -Source github"
```

macOS：

```bash
curl -fsSL https://raw.githubusercontent.com/yusen/zhangwen/main/install.sh | ZHANGWEN_SOURCE=github bash
```

安装脚本默认使用 Gitee；选择 GitHub 时需显式指定上述参数。后续更新沿用所选来源，两边版本以各仓库实际发布为准。

## 工作台

- 左上「模式」切换智能工程师、结构设计师和学习设计师；智能工程师和结构设计师可用，学习设计师提供界面与模板预览，学习业务待开发。平台以桌面 Web 为目标。
- K10、XIAO ESP32S3、ESP32-C3、掌控板 2.0 / 3.0；253 个模块，支持跨品牌选择、品牌及输入输出筛选。模块图片随包保存，新资料标明编程及电气参数是否完成联调。
- 新建项目先选择名称和本地文件夹，主控在工作台左侧选择，可稍后选择并保存。左侧已加入模块、中间掌问 AI、右侧编辑器；收起左栏仅扩展对话区。AI 代码先作为候选预览；保存、上传、回读校验和运行各自显示结果。
- 选择掌控板 2.0 时，AI 使用官方 v2.0.1 编程参考；不同主控使用各自资料。回复未附代码时明确提示，已完成历史回复中遗漏的有效代码可恢复为候选版本。
- 本地文件夹保存/加载项目，恢复对话及历史代码，编辑器版本下拉切换。历史文件按「代码／已保存版本」「代码／AI候选」「结构／3D造物」「结构／激光造物」分类，子目录使用版本号与用途名称；旧随机ID目录仍兼容加载，另存新文件夹可得到整洁副本。
- 结构设计师：保留硬件外壳设计和32份几何资料，另可不选硬件，通过收纳盒、笔筒、支架模板及受约束参数生成真实 CadQuery 模型与 STEP/STL。激光切割图纸有独立对话、历史和预览/切割图，导出毫米 SVG/DXF，无需 LaserMaker。详见[功能与使用边界](docs/PLATFORM_UPGRADE_20261018.md)。
- 结构对话和模型随同一项目保存/加载，文件夹 `structure/` 中可查看模型及报告。按所选硬件生成外壳草案无需AI；自然语言需求使用平台API设置。
- 学习设计师通过「切换视角」选择教师/学生工作台，顶部「问题引导 / 项目学习 / 成果档案」切换栏目，并提供海报和赛事资料入口。右侧「选择模板」先预览，确认后替换当前材料版式；选择仅临时保留，刷新重置，生成、保存、导入导出仍待开发。
- 「文件 → 项目程序」在项目子文件夹归档程序及测试记录，保留主控、模块和来源版本信息。
- 页面「API 设置」可分别配置三个模式，提供 DeepSeek、GLM、Qwen、Kimi 与自定义 OpenAI 兼容接口。Key 只存本机，不随项目导出；手工编程不需要 Key。
- 模块资料可按主控编辑本机示例、接线选项与支持主控，跨品牌使用须核对协议、引脚、电平和库。资料中的基础示例、诊断示例与未联调项有明确区分。
- 浏览器直连 MicroPython 设备，支持 main.py 上传、SHA 回读、运行、停止、终端与文件读取。上传回读通过后自动运行，运行中按钮切换为停止；代码全屏仍保留工具栏。五款主控随包提供已固定版本与摘要的官方默认固件，连接后自动检测 MicroPython 固件，非 MicroPython 提示固件版本不对并引导重刷；无响应时提示检查连接或重刷。点击固件并选择串口后直接更新，不做固件备份，保留写入前镜像/芯片/容量检查，不做固件回读校验；尚未完成真实刷写验收。

终端随新增输出自动滚到底部，重新打开显示最新内容。K10 上传检查可展开具体问题、预览官方屏幕 API 修复，接受保存后再上传；模块资料可独立标记「已核实主控」。结构设计入口为「3D造物 / 激光造物」，激光模板支持六面榫齿盒、圆角弯折盒及中文文字轮廓；圆角盒新版切缝交错接到上下边缘，旧图保留，可重新生成新版。实际弯折、刀缝与装配需按材料试切。

I²C模块资料显示默认/参考地址，可按主控保存实际地址与接线；这些记录不自动代表实物核实。AI优先沿用当前主控的本机案例，其他板型案例保持隔离。盛思超声波增加用户提供的单文件控制参考：0x0B写入测量命令、等待2ms、读取2字节换算厘米，无需替换固件；协议模拟通过，实物测距仍需用户上传后观察。掌控板2.0的P1为GPIO32、P0为GPIO33，原始 `machine.Pin(1/0)` 与板上P号不可混用。

部署仓库只保留构建及运行必需的源码、依赖锁、启动器、完整硬件资料与来源说明。不包含用户库、Key、设备备份、PPT、开发过程记录、截图、测试产物或桌面应用壳。运行依赖引用的原项目/Artifact/Hardware Skill 代码继续复用，未另造数据仓库。

数据默认在 Windows `%LOCALAPPDATA%\ZhangWen\data` / macOS `~/Library/Application Support/ZhangWen/data`，与程序版本分开。现有源码目录启动仍默认使用该目录的 `.data`；安装器不会自动读取或搬迁旧用户库。迁移、回退及自定义目录见 [部署指南](docs/DEPLOYMENT.md)。

## 已下载源码时

Windows 双击 `start-web.bat`，macOS 执行 `bash start-web.sh`。已有 Node 22+、Python 3.12+ 时也可以 `npm run setup` 后 `npm start`。Intel Mac 使用 Python 3.12/3.13；启动入口会自动选择兼容环境，几何依赖按处理器分别锁定。

安装入口先检查已有环境；缺失时直接下载 Node 24.14.0、Python 3.13.7（独立构建 20250918），核验固定 SHA-256，再用 Python 自带的 `venv + pip` 创建隔离环境和安装依赖，无需 uv。Windows 和 macOS 均适用。不修改系统 PATH、执行策略或凭据，无管理员权限要求。服务只监听 `127.0.0.1`。
