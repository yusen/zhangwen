# 掌问

**AI 创客工程工作台**

掌问是一款面向创客、教师和工程实践者的本地优先 Windows 桌面应用。它通过项目化对话组织需求分析、软硬件方案、代码、结构设计和教学产物，并由本地服务负责文件、设备与数据的安全边界。

> 当前 `v0.1.1` 为公开预发布测试版，适合体验和反馈，不建议直接用于关键生产环境。

## 主要能力

- 通过问题引导师、智能工程师和结构工程师协同梳理创意并形成可执行方案。
- 在同一项目时间线中管理需求、实现逻辑、硬件方案、代码和相关产物。
- 支持 DeepSeek、千问（Qwen）、智谱 GLM 和 Kimi 等云端模型服务。
- 本地保存项目数据，并在受控边界内使用 USB 串口、MicroPython 与硬件资料。
- 安装包内置桌面运行环境和本地服务，不要求预装 Node.js、Python、pnpm 或 Rust。

## 安装与首次启动

1. 下载 `Zhangwen_0.1.1_x64-setup.exe`。
2. 双击安装包并按提示完成安装。
3. 从开始菜单启动“掌问”。
4. 首次使用时创建本地账号，并在设置中配置所选云端模型服务的 API Key。

安装包包含本地 UI、FastAPI Sidecar、Python 运行时、内置 Agent/Hardware Skill、代码检查和设备辅助工具。安装完成后不需要另外安装开发工具或在线下载本地运行依赖。

## 重要安全提示

该预发布安装包尚未使用组织代码签名证书签名，Windows Defender SmartScreen 可能显示“Windows 已保护你的电脑”。请仅从本仓库 Release 页面下载，并在运行前核对上方 SHA-256。

API Key 不写入项目文件、安装目录或前端存储，在 Windows 中由 Credential Manager 保存。云端模型对话需要网络和有效凭据；断网不会影响本地 UI 和已保存项目数据的读取。

真实设备操作默认使用 USB 串口。文件上传、设备复位、Flash 擦除和固件烧录可能改变设备状态，请在确认板型、端口、备份和影响后操作。

## 数据与卸载

项目数据、非敏感配置、Hardware Skill、日志和设备备份默认保存在：

`%LOCALAPPDATA%\Zhangwen`

可通过 Windows“已安装的应用”卸载掌问。卸载程序默认保留上述用户数据，重装前请根据需要自行备份或清理。

## 当前已知限制

- 安装包尚未进行数字签名，可能触发 SmartScreen。
- 干净断网 Windows 环境中的最终外部验收仍在持续进行。
- 云端模型能力依赖用户自行配置的服务、网络和额度。
- 不同开发板可能需要 Windows 提供相应的 USB 串口驱动。
