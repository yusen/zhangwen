# Mosaico 功能融入掌问工作台

用户纠正了“打开完整面板”的方案。本版已删除完整面板弹窗、iframe 和 `/mosaico-panel` 容器，将固定设备接口接入掌问原生控件，沿用原三栏和连接位置。

## 使用位置

1. 智能工程师中选择 **ESP-Mosaico（Chat Coding）**。
2. 右上角「连接设备」填写 `http://192.168.60.126`，也可粘贴 `/#status` 链接；电脑和设备应在同一局域网。地址只在这里配置，不自动连接。
3. 中间对话区编辑、保存并显式发送 Chat Coding 任务。右侧「任务记录」保留任务版本、回执和个人观察；「设备工具」用下拉框切换设备功能。工具栏「设备设置」定位此处。
4. 不保存项目也能连接和查看管理功能。发送任务、文件修改和聊天附件须关联已保存的 Mosaico 项目；管理连接已有时，在连接弹窗点「连接项目聊天」。

| 原面板功能 | 掌问中的位置和行为 |
| --- | --- |
| 状态、重启 | 设备工具 → 设备状态；重启独立确认，收到回执后断开，手动重连 |
| Wi-Fi、时区 | 网络与时间；只提交改动字段 |
| LLM、ASR | 设备模型、语音识别；与掌问 API 设置独立 |
| IM、微信扫码 | 消息平台；主动申请/检查/采用扫码结果，再保存配置 |
| 网络、搜索 | 网络与搜索；搜索密钥和 HTTP 白名单 |
| 记忆 | 设备记忆；长期记忆只读，性格/身份/用户资料可编辑 |
| Web Chat | 中间 Chat Coding；最多4个附件，每个1 MB；回复文件通过本地固定文件接口下载 |
| 日志 | 实时日志；主动开始/停止、最近1000条、导出、断线不重连 |
| 能力、Lua 模块 | 设备能力、Lua模块；启用、设备 Agent 可见范围与保存 |
| 文件 | 设备文件；浏览、创建、上传、文本编辑、下载、目录打包、备份、删除及手动恢复 |

## 数据与操作边界

- 浏览器只访问掌问同源 API，不加载或执行设备 HTML/脚本；原面板入口和 iframe 已移除。后端只访问已连接的数字局域网 IPv4、固定原生路径，拒绝重定向与环境代理，不提供任意 URL/命令代理。
- 本地仅监听 `127.0.0.1`，沿用精确 Host/Origin 与写请求会话校验。管理控件不注册为模型工具；掌问模型没有设备或命令权限。
- 配置读取需要在本机内存暂时处理设备字段，返回浏览器时隐去已有密钥，只报告“已配置”。留空保持，清除须显式勾选；不写入项目、模型上下文或日志。扫码得到的 Token 仅在当前表单中采用，再由用户保存。
- 修改前校验配置修订或文件 SHA256。文件写入前备份到原 Artifact 版本历史，写后回读校验。结果未知时阻止继续写入，不自动重发；须先读取核对，再显式断开重连。
- 备份保留在本机 SQLite 原 Artifact 库，可在设备文件中下载、手动恢复；尚未纳入便携项目快照。页面一次列出最近100条且内容合计最多8 MB。目录下载最多8层/200项/8 MB，单文件最多1 MB，超限明确报错，不返回假完整备份。
- 二进制文件不能作为文本保存。只能删除单文件或空目录，禁止根目录和递归删除；空目录删除记录路径，恢复目录使用新建文件夹。长期记忆在记忆页只读。
- 附件由用户选取时显式上传并回读，随后点击发送才交给设备 Agent。后端核对项目、设备地址和附件摘要，拒绝任意设备路径。活动授权不随导入或服务重启恢复。任务、附件路径、回复、回执及个人观察复用原 Project/Conversation/Artifact。
- 保存、设备接收、回读校验、运行及实物观察分别显示。设备 Agent 可能执行 Lua，回复不代表实物通过。原 MicroPython/Web Serial 保留。
