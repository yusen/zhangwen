# 项目资料、自建模块与核实记录

2026-10-27，本地实现，尚未发布。以本文为已实现范围；同日早先方案中的批量自动提取、OCR、模块包交换等仍属后续规划。

## 使用入口

1. 在任一角色点击「项目 → 查看与添加资料」。列表显示文件、版本、参考状态和项目文件夹位置，可直接下载或移除；点文件名预览，展开「文件保存位置」查看归档路径。点「＋ 添加资料」选择文件、粘贴文字，或从项目文件夹的「参考资料」目录导入。导入先保存到本机项目记录，文件夹在后台同步，完成前仍可查看和下载资料。
2. 文件的「⋯」菜单可设置「自动参考」「优先参考」「停用」，也可「更新文件」「查看版本」。旧版本保留并可单独预览。下一轮智能工程师对话按当前项目、当前版本选取相关片段；助手消息下可展开「本轮提供了 N 份资料」查看实际提交内容、文件版本与行号。

「移除」需确认，会将当前资料移到项目资料回收站，可恢复。移除后不再提供给 AI，原文件、项目文件夹中的归档副本和历史对话引用保留。回收站状态随项目导出和重新打开，恢复仍保留原参考设置；同名资料在回收站时先恢复再更新，不覆盖旧版本。
3. 添加模块弹窗点击「新建我的模块」，或在资料预览点击「用这份资料创建我的模块」。先填名称、类别，可导入来源资料；已知参数与当前主控案例在「补充已知参数与案例（选填）」中填写。未知电压和电平可留空，**不要求负载电流**。保存后可筛选「只看我的模块」。
4. 模块资料默认进入「使用方法」：查看用途、供电/电平/接口、接线、当前主控示例与简短测试状态；程序原文与较长的接线参考按需展开。「尺寸与安装」查看外形尺寸、安装孔与机械维护入口；「参考资料」查看原始文档与修订。模块「⋯」菜单可编辑案例、修改我的模块参数、查看核实详情与记录。
5. 「记录测试结果」填写正常/异常及预期与实际现象，展开核对固件、接线与备注；驱动/功能实测须先保存当前主控案例。首次缺少条件时自动展开条件区。更多维度在「核实详情」按「型号身份、供电与信号电平、接线与通信、驱动与固件、功能实测、机械尺寸」分别记录。做编程不要求填写机械尺寸，也不要求六项全部完成才允许保存或对话。

## 资料能力与边界

支持 UTF-8 文本/代码、未加密的文本 PDF、DOCX。DOCX 包括正文及表格文字；PDF 只提取已有文字层，部分无文字页显示未分析。图片、扫描件、旧 DOC、复杂版式/图表语义和 OCR 尚不支持，不能视为已经完整阅读。解析失败明确提示，原文预览由用户复核。

单文件前端上限1MB，提取文字最多12万字符；PDF最多100页，DOCX的正文XML最多2MB。每项目最多20份资料，历史累计最多200个版本、约12MB。检索使用确定性的中文词片与关键词，按相关性及优先参考设置选取；每轮资料预算约1.2万字符，超过预算会明确提示未全文发送。这不是语义向量检索，不能保证每次都命中；可设置优先参考、拆分文档或在问题中指定文件与接口名称。

启用片段会发送给当前配置的模型服务。文件内容仅作为数据，无命令、设备或文件访问权限。平台记录的是实际提供的片段，不等于模型一定采用，也不代表回答已验证。当前接入智能工程师的 MicroPython 对话；结构设计师和学习设计师尚未接入该资料检索。

资料复用原 Project/Artifact 版本库，不新建平行项目库。快照保留原始内容、提取文字、版本、摘要和对话引用；保存文件夹另将原文件归档至「资料归档/资料ID/V号/原文件名」。重新打开快照恢复资料，不自动扫描所有附件。原文件归档有摘要保护；失败保留本机记录并提示文件夹同步状态。资料不加入设备上传清单，上传仍只含 main.py。

## 硬件核实语义

- 灰色「未核实」：没有当前主控的有效记录。
- 蓝色「资料已核对」：用户填写来源并确认资料，不等于实物测试。
- 橙色「待实测」：尚无实测结果。
- 绿色「用户报告功能通过」：用户填写了本次条件和现象，并非平台自动认证。
- 红色「测试异常」：记录与预期不一致，不能直接判定硬件损坏。
- 橙色「需复核」：相关案例、接口或参数改变，原记录条件需复核。

记录关联当前模块、主控、维度、时间、相关内容摘要，以及固件/库、接线、来源和预期/实际现象。驱动/功能通过或异常须先保存该主控案例并填写条件；固件版本未知可明确写未知。历史保留在同一 Hardware Skill 的用例文档中，界面每维度展示最新记录。代码、接线说明或接口变化影响驱动/功能；供电/电平改变影响电气记录；机械资料变化影响机械记录；新增核实记录本身不会使记录失效。板外固件、接线或实物变化无法自动感知，用户须重新记录。

其他主控通过不能让当前主控变绿。旧版主控勾选保留为「旧版标记，条件待补充」，不再自动加入兼容支持列表。声明支持、规则检查、上传运行与人工观察仍各自显示。已知供电/信号电平冲突仍检查；负载电流不参与核实和兼容门槛。

自建模块复用原 Hardware Skill 原子创建/更新与SQLite投影，默认未核实；仅创建 my-module-* 新包，不覆盖内置模块。当前为手工确认事实与来源，并非模型自动解析整本说明书生成驱动。模块原始附件建议同时导入项目资料。个人模块包的跨电脑导入导出、编辑完整来源、结构化证据分类、适用/不适用与状态筛选等尚未实现。
