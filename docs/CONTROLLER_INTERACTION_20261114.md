# 单主控与多主控使用同一套交互

2026-11-14，按用户“多主控应和单主控的交互是一致的”调整。

工程师页面继续在左侧“项目主控”切换各块主控。新增主控和更换主控均使用原 BoardPicker；“管理项目器件”使用同一项目器件弹窗、模块库、资料与示例入口。各块主控共用工具栏、连接按钮、模块列表、聊天标题和输入框、编辑器标题栏组件，位置和键盘操作保持一致。

每块主控沿用“描述需求 → 查看生成稿 → 采用或保存版本 → 显式上传并运行”的流程。生成稿在右侧只读预览；返回原稿保留手工代码，保存生成稿替换手工草稿前确认。项目保存及 Ctrl/Command+S 保存当前主控；器件弹窗内优先保存器件选择。保存器件不覆盖未保存代码；无新修改时不重复创建代码版本。代码检查、屏幕/引脚修复预览、导入导出、历史、缩放、全屏、REPL、自检、板载文件与固件准备均从原有位置进入。

“项目程序”使用真实项目文件夹，可按名称保存和回读程序副本。副本携带主控标识、名称、主控记录修订与代码版本，各主控默认只列出自己的程序；旧副本归属于项目原主控。另存文件夹仍携带全部已核验副本。上传回读、运行提交和用户观察分别记录，不能用同型号另一块板的记录证明通过。

各主控的对话、需求草稿、代码、预览、模块联调对象、端口、上传凭证、备份和执行记录保持独立。切换不会重新连接、上传或运行。后台主控可保持连接，当前页面只展示选中主控的工具；其他工作角色的保存快捷键仍处理该角色内容。

更换型号须先断开该主控；原代码和对话保留。历史版本和消息记录原板型、模块来源，旧记录在显式保存时补充原归属。新板对话不会续接旧板私有对话；旧板历史可展开查看。模块联调对象须属于当前已加入模块，普通后续反馈延续当前对象；切换模块或退出不代表实测通过。并发冲突保留手工稿，未知结果不自动重发。

所有主控仍在同一 Project/Artifact 内，通过“三师共用资料”共享已保存主控、模块、程序及参考资料，私有对话和未保存手工稿不进入共享投影。模型仍仅输出文字与代码。附加主控目前使用 MicroPython，原 Mosaico Lua/Claw/本机 Idea 开发路径保持；本轮不扩展第二块 Mosaico、同步启动或板间通信。

自动化验证采用隔离项目、模拟模型回复与 Fake Web Serial，实际主控和整机效果仍待实物验收。完整结果见 CONTROLLER_INTERACTION_20261114_VALIDATION.json。本轮仅本机开发、默认无 Idea 导出与本机加载，不提交推送或分配发布版本。
