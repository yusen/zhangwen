# 掌问 V0.4.2026.1115.03

本次将掌问产品更新同步至GitHub main和Gitee master。两个渠道使用同一版本文件和无Idea的发布清单，仅发布产品源码、运行资源与使用说明。

## 产品更新

- 学习任务清单保留稳定身份，支持修订、替换及停用；保留旧观察和未保存手工稿，保存数量以实际结果为准。
- 测试关联覆盖全部主控，无效关联定位到具体条目；观察保存参与主控的程序版本、摘要与器件资料，相关改动提示复测。
- 当前任务优先适用已确认目标，保存观察后保留所选任务及表单归属。
- 学习设计师支持完整纯文字讨论，无需每次新增目标和测试；截断时保留输入和已有记录。
- 智能工程师按实际代码候选显示交付状态，协议讨论可以直接阅读，输出过长时提供分步恢复说明。
- 学习区可平等管理、命名不同主控；各板独立开发，共用资料明确实际板数与身份。
- 三师读取启用参考资料的正文或相关片段，显示本轮实际采用来源和截断说明。
- 项目资料支持图片及本机视频关键帧。使用者核对说明后保存，可显式请求单图分析，整段视频不上传。
- 结构检查返回本次结果，保持设计版本、对话和验收依据；模板异常给出明确错误。

保留此前的Mosaico多主控、异构板混用、整机结构资料与Mosaico / micro:bit官方产品配图。

同一产品源码已通过166项前端、80项不同相关后端、4个浏览器场景及本机视频关键帧变体。发布副本另外完成独立TypeScript strict / Vite构建、无Idea接口、混合主控和完整部署冒烟，包含激光图与真实STEP生成。未宣称后端全量测试或真实硬件验收通过。

本版仅调整发布资料范围和版本说明，产品代码与已经验证的发布副本保持一致。

MicroPython、Mosaico Lua及显式切换的原生Claw保留。Mosaico Idea原生应用开发及SDK继续仅保留在本机；用户项目、API设置、缓存和生成工程不上传。真实设备运行、制造装配与多板通信效果仍需实际验证。
