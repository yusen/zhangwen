# AI 检测使用与验收

2026-10-15，浏览器打开「API 设置」，填写Key、选择模型，点击「测试连接」。留空Key时使用已保存Key；检测尚未保存的输入不会改变原配置。检测会发送一条“只回复OK”的简短消息（16 tokens上限），不提交项目代码、历史对话或硬件资料。

逐项显示网络连接、Key认证、所选模型、账户可用性和实际生成。前四项通过不能代替完整回答成功；只有收到有效正文、正常结束和[DONE]才显示「实际生成检测通过」。显示生成用时、首字时间和保活次数。网络/模型列表最多10秒，账户8秒，实际生成30秒；可随时取消或关闭弹窗，中断上游连接并释放检测锁。编辑Key或模型会清除旧结果，防止误用上次结论。

| 检测情况 | 建议 |
|---|---|
| 网络未通过 | 检查本机网络、DNS、TLS、防火墙或代理，再测；尚不能判断Key是否有效 |
| Key/访问权限未通过 | 核对完整Key及账户权限 |
| 模型不在列表 | 选择当前可访问模型，不会自动更换 |
| 账户不可用/402 | 到DeepSeek控制台核对余额、账户状态 |
| 429/5xx | 供应商限流或服务异常，稍后手动重测 |
| 已受理但只有保活 | 生成服务没有及时输出，可能排队或暂时异常；等待恢复或手动选其他模型 |
| 有正文但未完整结束 | 本次不能记为通过，稍后重测 |

后端为受Host/Origin/会话保护的POST `/api/settings/ai/test`，NDJSON check/done/error事件定义在原跨端契约。只调用固定DeepSeek地址，Key/原错误体/测试正文不会回传或存入项目；报告仅显示结论和计时。服务内一次只允许一个检测，原项目对话和设备权限不变。
