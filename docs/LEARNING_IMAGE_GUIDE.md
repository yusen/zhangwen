# 学习设计师图示

在学习设计师的造物指导中，点击对话标题旁的“生成图示”，可生成线路方框图或项目方案图。

首次使用先配置图片模型 API，也可从“AI 设置 → 图片模型 API 设置”进入。填写图片服务基础地址、模型和 Key；图片模型与文字模型分开配置。每次生成一张图片，可能产生服务用量。

生成时会参考已保存的项目目标、主控和器件、实际条件、结构说明及相关资料文字。私有对话、手工程序草稿和原始图片、视频不随请求发送。

图片返回后先作为待核对图稿保存，可以下载或重新打开。检查中文标注、器件数量和关系，补充或修改说明，再点击“核对后加入共用资料”。三师参考保存后的说明文字，不会自动读取原图。图稿用于讨论方案，接线和加工仍需依据器件资料与结构检查结果。

## 服务要求

- 支持 OpenAI Images 兼容接口的固定 `POST /images/generations`，返回 `data[0].b64_json`，图片为 PNG、JPEG 或 WebP。只返回 URL 的服务暂不支持。
- 可选服务默认格式，或显式请求 `response_format=b64_json`。尺寸是否可用以所配服务为准。
- 图片 Key 保存在本机独立设置中，不进入项目导出，也不继承文字模型 Key。生成不提供设备或命令权限。
- 遇到超时或结果未知时，先检查已有图稿和服务记录，系统不会自动重发生成请求。
