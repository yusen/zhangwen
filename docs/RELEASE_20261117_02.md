# 掌问 V0.4.2026.1117.02

本次更新同步至 GitHub main。Gitee 保持 V0.4.2026.1115.03，默认安装命令仍使用 Gitee。

## 安装修复

上一版本在 Windows 自动安装检查中选中了 Python 3.15.2，锁定的 CAD 原生依赖没有对应安装包，导致安装准备失败。安装器原有版本检查只限制最低版本，本次补上与锁定依赖对应的上限。

Windows、Apple Silicon 采用 Python 3.12–3.14，Intel Mac 采用 Python 3.12/3.13。启动入口跳过不兼容的本机解释器，继续查找可用版本；没有时沿用固定摘要校验的托管 Python 3.13.7。原环境按现有备份规则保留，安装失败仍保留原选中版本。直接运行 `npm run setup` 时也会在安装依赖前检查版本。
