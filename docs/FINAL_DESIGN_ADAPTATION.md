## 布局与视觉

标题栏置于工具栏上方，显示品牌、main.py、未保存标记、当前项目、保存位置和字号，右侧主题切换。下方保留已加入模块、AI对话、代码编辑三栏。左栏桌面276px，AI/编辑器随宽度分配；手机通过标签切换，工具栏内部滚动。

浅深主题覆盖代码高亮/光标/选区、模块、终端、检查结果、弹窗；mu-theme存于当前浏览器，刷新恢复。系统字体，无外部字体加载。

## 交互对应

| 入口 | 实际行为 |
|---|---|
| 新建 / 加载 / 保存 | 未命名项目直接工作；首次保存命名成v1，后续不可变版本；加载恢复代码、主控、模块与对话，未保存切换确认 |
| 主控板 / 添加模块 | 左栏选主控；原Hardware Skill系列筛选，K10→DFRobot、XIAO→Grove；已加入卡片按输入/输出分组，候选浮窗搜索、分类、多选确认 |
| 载入模块 | 读取原资料包examples的.py或Python围栏，先预览，再明确替换main.py草稿；无示例如实提示，保存/检查/上传独立 |
| 上传 / 运行 | 原Web Serial清单、备份、校验与确认；上传回读一致后单独提交运行，不宣称实物成功 |
| 接线 / 文件 / REPL | 原接线文档、历史代码版本、真实串口终端；接线仍为资料，不是绘图编辑器 |
| 检查 / 格式化 | 检查静态语法与原库规则；格式化仅按Python语法整理四空格缩进，Ctrl+Z可撤销 |
| 放大 / 缩小 / 帮助 | 编辑字号80–160%，真实使用说明和键盘弹窗 |
| 退出 / 返回工作台 | 无设备连接和进行中任务时收起工作区，未保存提示；保留项目/草稿并可返回，服务继续运行 |
| AI对话 | 原可选真实接口；未命名工作区首次发送自动保存项目，未配置时打开API设置；Ctrl/Cmd+Enter快捷发送，失败保留输入并可重试；代码建议明确接受后修改草稿 |

参考里的sensor.py和示例运行数据属于演示。本版仍仅main.py、64KiB，未扩展多文件或自动设备操作。74个原包全部保留，71包可见；K10共68模块（54输入/14输出）。Grove编程包仍缺失，XIAO显示真实空状态。

## 实现与验证

App.tsx负责状态与入口，MuTool.tsx负责工具样式变体；style.css → mu.css → final-design.css按顺序加载。Editor.tsx通过主题变量和EditorHandle.formatIndentation实现高亮及可撤销缩进。ModuleCard.tsx增加载入入口。没有新增平行硬件数组、项目库或后端命令权限，V1保留原样。

strict构建通过，最新Edge浏览器回归10项通过（20.3s）；未改API17项/协议10项沿用前次记录。实际3080浅深×375/720/1024/1440八种布局无横向溢出，68项网格滚动/弹窗键盘/主题和草稿刷新通过，0页面异常、无生产写入；471项原保护文件摘要一致。
