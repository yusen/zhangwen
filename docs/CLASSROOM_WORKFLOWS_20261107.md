# 面向课堂的三师工作台

学习设计师提供三个入口：教学设计、造物指导、成果档案。教师、学生和DIY爱好者决定作品目标与协作方式，三个角色共用同一项目的已保存资料。

## 教学设计

可以从空白主题开始，不必先选硬件；也可基于当前作品的已保存目标、器件和实际记录设计。说清学生年级、已有基础、课时和主题后，生成三阶六维教案大纲：探索关注创新、关心，造物关注设计、合作，迭代关注批判、成长。输出含活动、教师追问、观察证据及评价建议。

生成稿自动保存为独立文档。可手工编辑并保存新版本，导出文本或可打印HTML；已有手工修改在生成新稿时保留。教案是待教师核对的方案，预期证据不代表已经发生的学习效果。

## 造物指导

先通过对话明确想做什么，选择主控和模块，在对话区确认器件后，可以分别讨论模块测试。三个角色平等，未选定或保存主控时也可切换，之后可在任一角色页面选择。

对话逐步整理作品说明（PRD），包括目标、使用者、功能、范围、参数、异常处理和完成条件。手工表单按需展开；确认作品说明后继续当前制作任务，记录实际反馈。具体要求由用户带入结构或智能工程师的输入框，核对后发送。

已确认的需求变更进入共用目标与复测判断。共用资料与发起协作分别处理；用户选择需要协作的伙伴，三个角色不自动替用户发送任务或操作设备。

## 成果档案

展示海报文案、申报材料、过程日志及图片统一归入成果档案。可以生成或手工编写文档，也可导入文字、PDF、Word和CSV材料。导入的已有材料默认不提供给AI；需要引用时由用户在项目资料中选择。

## 项目保存与制作工具

新建项目自动在系统文档目录的“掌问项目”中按项目名称建立文件夹，重名时加序号；可通过“项目 → 另存为…”指定其他位置。“项目”下拉菜单集中提供添加资料、打开项目文件夹、查看文件列表与查看共用信息。外部修改或版本冲突会保留文件并提示处理。

结构工程师顶部只保留3D打印和激光切割两项制作功能；安装尺寸和结构器件资料仍可在结构侧栏选择。三个角色均可选择和调整主控、模块。智能工程师的板载文件位于连接设备旁。

舵机和超声波结构资料按原Hardware Skill的器件身份关联，中文名称也可搜索。不同型号的尺寸与接线不能互相代替，仍需核对实物。

保存、上传回读、提交运行和实际观察分别记录。模型只生成文字与代码；设备操作由用户明确触发。本发布保留MicroPython、Mosaico Lua和Claw，本机Idea开发与SDK继续保留，部署包不包含Idea。
