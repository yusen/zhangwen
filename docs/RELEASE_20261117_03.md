## 安装修复

修复 Windows 中文桌面快捷方式保存失败。上一修订已经通过 Windows 的 Python 依赖安装及页面构建，但在英文系统保存“掌问.lnk”时出错。本次改用 Windows Unicode Shell 接口保存与读取快捷方式，保留名称、图标、启动参数和窗口设置；只移除指向同一安装的旧英文入口，其他安装的快捷方式保留。

保留 Python 兼容性修复：Windows、Apple Silicon 使用 Python 3.12–3.14，Intel Mac 使用 3.12/3.13。启动入口跳过不兼容解释器，没有可用版本时使用原有固定摘要的托管 Python 3.13.7，不修改系统 Python。
