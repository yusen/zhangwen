# 2026-10-18 三师平台扩展

## 结构设计审查与改进

此前流程以32份硬件几何资料和矩形外壳为中心，未选硬件时缺少独立建模入口；所有结构内容共用对话；模型参数和原始程序边界需要保持。现保留原硬件外壳流程，同时新增独立参数化3D与激光图纸通道。

修正模板后文字修改被模板覆盖的问题；文字修改带前一份设计数据重新请求结构模型。新模板/3D与图纸类型校验，项目导入时也校验图形边界、数量和结构。缓存结构目录请求并去除重复项目读取，避免每次切换多次拉取相同目录。结构Artifact版本与两条对话改为同一SQLite事务，写入故障一起回滚；不再存在只存版本、没存对话的半完成状态。原Project/Conversation/Artifact、硬件资料与旧结构版本继续使用。

## 使用

模式→结构设计师，顶部选择“3D建模”或“激光切割图纸”。两边对话、历史筛选及临时输入独立；发送/构建仍为项目保存新的不可变版本。临时输入在切换通道时保留，换项目/刷新时清空；已发送对话随项目目录保存和加载。

3D：不需要添加硬件。可直接使用开口收纳盒、圆柱笔筒、L形支架模板，调毫米尺寸，确认后由CadQuery生成真实STEP/STL和含注释的建模代码。也可配置结构API，用自然语言提出需求。模型只返回受约束JSON，服务端用固定几何操作构建，绝不执行模型返回的代码。当前支持盒/圆柱/球及加减、旋转、平移；复杂自由曲面和艺术造型需要简化，不应宣称任意3D造型均已支持。原硬件外壳、安装面/朝向/布局与真实模型保持。

激光：矩形挂牌、圆形挂牌、五片胶合收纳盒模板，可通过结构API描述其他平面图案。右侧“设计预览”与“切割图”分别展示材料与线稿，导出SVG、DXF和预览SVG。毫米单位，CUT红层/ENGRAVE蓝层。只校验范围、数量、开放切割路径与完全重复数据，不代表已完成交叉路径、最小孔距、材料强度、装配或刀缝补偿；胶合盒不含榫齿。名义尺寸导出，刀缝由加工软件处理。没有机器控制、功率设置或自动加工。

平台独立生成图纸文件，支持毫米尺寸、材料厚度、切割/雕刻层及预览/导出，不需要安装或启动LaserMaker。

## 按模式配置API

顶部API设置→配置模式：智能工程师/结构设计师/学习设计师。各自保存地址、模型、Key，检测使用当前所选模式与表单。未单独配置时沿用工程师配置；保存后成为独立配置。旧平面设置文件原样读取，不自动改写；原来不指定mode的设置接口继续只返回原有三项公开字段，显式选择mode才返回模式/继承信息；首次为结构/学习模式独立保存才增加modes对象。Key不会回显、写入项目或带到更换后的地址。DeepSeek、GLM、Qwen、Kimi快捷项自动填地址/模型，模型ID始终可编辑；其他OpenAI兼容服务仍可填。学习设计师依然是UI预览，本轮只准备其独立配置，未虚构学习生成功能。

供应商参考（2026-10-18核对）：
- DeepSeek https://api-docs.deepseek.com/zh-cn/quick_start/pricing
- GLM https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3
- Qwen https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope
- Kimi https://platform.moonshot.cn/docs/guide/kimi-k3-quickstart

快捷模型不是自动探测账户可用性，需在页面点击“测试连接”检查实际账户/模型；更换服务商清空当前输入Key。

## 默认固件、代码与版本

五款主控镜像及本轮来源核对见resources/firmware/README.md和manifest.json，部署导出包含这些本地资源。固件页自动加载当前主控镜像并校验大小/SHA/ESP头；用户勾选确认后，点击“一键刷入默认固件”，选择串口即自动识别芯片、检查容量、备份覆盖扇区到IndexedDB并尝试下载、写入与SHA回读，保留失败时恢复范围的入口。仍要求用户保存设备文件并进入下载模式。没有手选文件或偏移，没有整片擦除；备份仅涵盖覆盖范围，不是全设备备份。下载被浏览器拦截可重新下载，跨会话备份导入恢复尚未提供。

掌控板2.0官方合并包前4096字节填充，因此默认偏移为0，不能对本镜像用旧4096默认值。掌控3.0厂商包没有公开语义版本，日期+SHA固定；K10使用官方MicroPython 0.9.8，非出厂Arduino固件。最新只表示核对日官方发行/默认链接，后续不会在后台自动替换镜像。

MicroPython生成提示要求用途、接线/参数、主要步骤、异常处理的简短中文注释，参数化建模输出含确定性注释；不改写已有历史程序。模型未遵守注释要求时仍需用户核对，本轮不作语义注释自动修补。版本下拉显示“V号 · 用途名称 · 阶段/来源”；旧程序从原回复摘要或代码注释推导名称，原不可变内容和版本号不改写。

## 验证边界

功能验证使用隔离数据、Fake模型、Fake Flash及真实本地CadQuery文件，没有请求用户真实付费模型、操作真实串口/刷固件/激光加工。Mac资源路径使用Path和前端Web Serial，不依赖Windows绝对安装路径。部署的原生平台验证以对应提交的GitHub Actions结果为准；浏览器设备和加工效果需单独实物验收。
