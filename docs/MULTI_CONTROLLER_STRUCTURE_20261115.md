# 多主控的整机结构设计

同一项目的各主控继续平等、分别编程，结构工程师面向整个作品组织机械方案。用户视频中的转臂采集板、底座电机/测速、独立显示部分属于共同结构设计范围，而不是只为当前选中的板生成一个外壳。

## 本轮接入

结构对话读取全部已保存主控及其器件的原 Hardware Skill 机械资料，按修订引用外形、安装孔、开口、坐标原点与避让。相同型号的尺寸档案可以复用，但不同主控身份保留为不同实物；Mosaico 与其他板混用不会被替换为同一种板。既有“三师共用资料”继续提供已保存目标、程序与结构，私有对话及未保存程序不进入其他主控上下文。

左侧增加“整机结构”范围清单，3D 与激光设计共用该范围。安装编辑器按主控分别安排器件，旧单板名称与数据格式保持。读取主控失败时不按缺失清单继续生成，用户可重读，需求草稿保留。

激光盒安装记录增加可选 `controllerId`，省略时为原项目主控。唯一身份由主控与器件共同构成；同型号多板可分别设置面板、位置和朝向，仍参与同一图纸的包络、切口与同面碰撞检查。来源记录保留主控身份、名称、器件资料修订和机械档案，历史回放和导出无需改写为当前库版本；归属错误、重复身份、篡改来源拒绝。已有不含 `controllerId` 的版本保持原序列化格式。

## 结构协同内容

自由设计与案例改造都考虑共同底座、分板托座、连接件、供电安装位、接口朝向、线束和检修空间，区分固定部分与运动部分，记录传感器朝向、视野及全行程避让。旋转装置还需要说明转臂、半径调整、线束路径和配重的验证条件。只改局部时保留其他部件；未要求共用外壳时不强制所有板塞进同一盒子。

结构变化涉及引脚、通信或控制程序时，说明需交给智能工程师的条件，不声称已替各板改程序或完成联调。图纸和模型通过软件检查，只代表所列检查范围，不能证明强度、动态平衡、完整运动无干涉或实物适配。

## 范围与后续实物验收

本轮不直接生成视频装置的精密加工模型，因为视频没有给出主控修订、轴/电机尺寸、转臂尺寸及连接实测资料。实际制作时先确认分工与结构草案，再补齐精密配合资料、逐件试装和整机低速观察。

现有能力限制继续适用：安装编辑器用于圆角盒/榫齿盒面板；自由3D和固定案例沿用各自现有几何能力；没有新增通用装配约束求解、动态仿真、自动线束布线或全系统同步运行。每版安装图最多33项安装对象。未经用户明确设备操作，不上传、不运行设备。

验证详情见同名 `VALIDATION.json`；本机完整开发及 Idea/SDK 保留，无提交、推送或发布。
