# Mosaico 与其他主控共同开发

用户要求 Mosaico 加入项目主控，并考虑与 micro:bit、ESP32 等不同型号共同开发。本轮在原多主控入口中允许添加 Mosaico，支持原主控为 MicroPython 或 Mosaico，也支持多个 Mosaico 与 MicroPython 混合。所有主控同级选择，顶部菜单、连接、编程方式、对话、代码及移动页签随当前主控。

Mosaico 复用原 Lua/Claw 编程界面、固定设备协议与用户点击上传运行流程，独立保存代码版本、对话、需求草稿、局域网地址、文件备份、观察及运行记录。micro:bit、ESP32 等沿用各自的浏览器 Web Serial 通道。切换主控不提交设备任务、不切断另一主控的连接；不同主控占用同一 Mosaico 地址时明确拒绝连接，连接期间更换主控型号也会拒绝。原单板和附加 Mosaico 的 Lua/Claw 输入按钮均放到输入框旁，Lua 输入区删除底部重复提示。

各主控的已保存程序、器件与原三师共用项目目标、结构、资料进入同一共享投影。Mosaico 使用已保存的 Lua 版本，其他板使用已保存的 MicroPython 程序；私人聊天与未保存代码不进入其他主控上下文。Fake 模型测试验证 Mosaico 生成能看到已保存 micro:bit 程序，micro:bit 生成也能看到已保存 Mosaico Lua。共享资料用于设计协作，板间实际通信仍需确定协议、引脚与数据格式，并分别上传和实测。

状态保存在现有 Project 的开发通道 Artifact 内，新增嵌套的 Lua/Claw/备份记录，无隐藏 Project 或平行项目库。作用域接口复用原服务：`/api/projects/{pid}/channels/{cid}/runtime/...`。模型仍只有文本和代码输出权限；保存冲突、备份、摘要检查、回读、boot_id、连接标识和结果未知不重发规则保持。项目快照与文件夹导出包括各 Mosaico 的代码和历史，不恢复设备连接授权。

附加 Mosaico 本轮提供 Lua 与设备原生 Claw。未发布的本地 Idea 源码、工程和 SDK 保留，未将 Idea 扩为附加主控，也未恢复其发布。默认无 Idea 的独立导出目录是 `.publish/mosaico-channels-20261114-ui-verified`；本轮仅准备验证，没有提交、推送、分配版本或发布。

验证记录见 `MOSAICO_CHANNELS_20261114_VALIDATION.json`。161 项前端单元、184 路径资产清单、8 项新增后端、3 项新增浏览器场景通过；原后端回归首轮 80 通过、2 失败，修正型号限制旧断言与可选字段序列化后，对应 2 项定向通过。额外原混合主控与学习交接 2 项浏览器场景通过。最终输入区调整另做手机 Lua/Claw 定向复查，所有设备与模型均使用 Fake/隔离请求。

原 30801 服务已由原启动器更新，当前 PID 29796，入口及四项资源与本机 dist 字节一致。备份包含 2995 个文件，SQLite 完整性通过；前后 164 张表、57 个项目的原记录与设置、项目位置、471 份保护源码及 Git HEAD/index 保持。仅运行地址与硬件目录缓存元数据更新。
