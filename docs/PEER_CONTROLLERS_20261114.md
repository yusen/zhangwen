# 平等多主控与独立对话

2026-11-14，按用户截图调整本机工作台。

工程师左侧“项目主控”中选择“单主控 / 多主控”。多主控下，各主控以同级卡片选择，可重复添加相同型号，最多八块。点击主控切换其对话和代码；连接、对话、未发送需求和手工代码在切换时保留。单主控显示不会删除已经保存的其他主控。

各主控共用同一 Project、作品目标、参考资料、结构和已确认条件。“三师共用资料”以同一格式列出所有主控、模块和已保存程序版本。私有对话和未保存草稿不加入共享资料；模型仅处理本轮指定主控，不代其他主控修改或操作设备。原单板测试记录注明板型，不能代表其他主控或整机通过。

对话框底部的重复操作提示已删除，发送箭头与输入框并排；支持 Ctrl / Command + Enter。主控选择支持上下方向键与 Home / End。手机从“硬件库”切换主控，再进入“掌问 AI”或“代码”。

每个主控分别连接、自检、保存、上传并运行。程序历史、草稿、端口、浏览器备份继续独立；上传仍需用户显式点击，失败停止、未知不重发。已有项目数据和原器件库复用，未迁移生产项目。额外主控目前支持 MicroPython；原 Mosaico Lua/Claw 保留，未新增第二个 Mosaico 或同步启动。
