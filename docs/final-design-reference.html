七条硬约束

  • 容器家族完全统一。13 个图标用同一套：40px · 圆角 9px · 内高光 · 字形 22px / 线宽 2.6 / 圆头。禁止任何图标单独偏离。
  • 圆角恒定为边长 22.5%。尺寸变体（40→34→30）圆角按比例缩放，线宽反向加粗（2.6→2.9→3.2）。
  • 内高光不可省略。inset 0 1px 0 rgba(255,255,255,.22) 是"图标感"与"色块感"的分界线。
  • 悬停只提亮不改色相。filter: brightness(1.08)，保持色彩语义稳定。
  • 「运行」是唯一品牌金。全应用唯一一处品牌色出现在最高频操作上。必须用 #B8933C 配深墨字，不能用浅金配白字（2.4:1 不达标）。
  • 品牌金不进工具栏其余位置。13 个图标全染金 = 品牌墙，失去工具克制。品牌感的其他落点：启动图标、AI 面板标题、焦点环、选中态。
  • 状态色语义锁定。绿=成功 / 红=错误 / 黄=警告，永不挪作装饰。diff 的绿红是行业惯例，不随主题变化。
