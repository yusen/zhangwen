## 约束问题与处理

| 项目 | 发现及处理 |
| --- | --- |
| 资料覆盖 | 184个模块缺电压或逻辑电平，252个模块缺正值峰值电流。初步粗算185含纯电源无需逻辑电平的一项，现排除；不补造事实 |
| 部分未知字段 | 旧Web适配器排除整个模块，已知字段也跳过；现按字段筛选后调用原声明式算子，主控/驱动规则也继续检查 |
| 纯电源 | 5V/3A电源曾因逻辑电平为0被排除；现不要求纯电源具有逻辑电平，正常参与供电/电流规则 |
| 电流 | 0占位不计入求和曾可能产生余量PASS；现有未知负载/容量即警告并撤去完整预算PASS，已知超额仍失败 |
| I²C | 现采用当前主控保存地址或资料默认值；未知地址提示补齐，重叠提示“可能”。未记录总线分配，不能声称确定同总线冲突；多个主控不套用其中一个的记录 |
| 身份覆盖 | 临时customProfile曾可覆盖同ID原模块；现拒绝与原模块或其他临时资料重名 |
| 机械映射 | 保留原mounting声明。侧向贴合、未实现的边缘卡持、有孔但未声明孔固定均阻止外壳生成；包络中心坐标可检查孔位越界，PCB中心不当作包络中心 |
| 间隙 | 原格式允许0而Node要求大于0，现统一为非负值；参数通过不表示实物适配 |

仍需补齐：原SEN0193/DFR0523浇水拓扑针对K10，跨主控会保守拒绝，不能作为全主控认证。现有检查没有完整的项目级GPIO/ADC/PWM占用、总线分配、电源分路与瞬态负载模型。结构适配支持现有底板/盖内安装；未声明贴合面仍有待确认的-Z默认方向，结果已保留说明。原allowed_enclosure_surfaces虽保留在声明中，安装面覆盖尚未完整执行该限制，应作为后续约束项补齐。孔位/原点、开口和避让区须来自准确型号资料或实测。用户主控标签、编程案例和静态检查不能替代实物验收。

## 项目输出

保存时只读接口导出当前已保存选择的模块资料，以及结构历史中明确关联的模块/结构专用件。每模块目录包括当前用户案例、约束、机械档案和参考模型；临时资料按结构版本归档；缺项明确说明。当前副本不能反推过去加工版本所用尺寸。

内容摘要决定资料版本。更新后保存会新增资料版本，旧副本保持；旧项目下次保存即可新增硬件目录。项目装配/激光图继续位于 `结构/3D造物`、`结构/激光造物` 的版本目录，一个装配可涉及多个模块。

副本不自动安装/导入硬件库，不执行参考Python，不进入设备上传清单。原 `zhangwen.project.json` schema1及恢复流程保持，跨机恢复仍需本机存在对应模块资料。外部改动副本时拒绝覆盖该文件及项目快照，可另存新目录。路径/容量/摘要写前检查、写后回读；接口检查项目修订并持锁读取。

验证见同名前缀的AUDIT/PRESERVATION/VALIDATION JSON。仅隔离库/浏览器OPFS/Fake协议；无真实AI、设备、加工验收，无生产重启或发布。
