# 掌问 V0.4.2026.1115.02

本次将多主控制作流程修复与向心加速度学习案例同步至 GitHub main 和 Gitee master。两个渠道使用同一版本文件和无 Idea 的发布清单。

## 本次改动

- 学习任务清单保留稳定身份，支持修订与替换，保留旧观察和未保存手工稿，保存数量以实际结果为准。
- 测试关联覆盖全部主控，错误定位到具体条目；观察记录参与主控的保存版本、摘要与器件资料，相关改动提示复测。
- 学习设计师支持纯讨论；工程师按实际代码候选显示交付状态；截断保留输入，并提供分步继续说明。
- 学习区可平等管理、命名不同主控；各板独立开发，三师读取共用资料正文，并显示实际采用来源。
- 项目资料支持图片及本机视频关键帧。先核对说明后保存，可显式请求单图分析，整段视频不上传。
- 结构检查只返回当前检查结果，保持设计版本与对话；异常模板给出明确错误。
- 新增九页向心加速度学习案例、两张真实试走截图、任务示例与实验记录模板，解释学习设计师、智能工程师和结构工程师如何协作。

前一版的 Mosaico 多主控、异构板混用、整机结构资料与 Mosaico / micro:bit 官方实物配图同时保留。

## 验证依据与实际边界

修复阶段已通过166项前端、80项不同的相关后端测试、4个浏览器场景及原视频关键帧变体；测试使用隔离数据及Fake模型，没有将模拟结果当作实板验收。默认无Idea导出已通过清单、Python语法和独立TypeScript检查。具体修复与复测范围见[修复记录](VIDEO_CASE_REPAIR_20261115.md)，未宣称后端全量测试通过。

向心加速度案例基于已有真实界面试走，四板程序及转臂孔位概念样板已保存；完整整机结构、制造装配、上传运行、板间通信和物理实验仍需实际验证。案例中的对话是教学示例，实验数值待实测填写。

MicroPython、Mosaico Lua及显式切换的原生Claw保留。Mosaico Idea原生应用开发及SDK继续仅保留在本机，不包含在本次公开部署；用户项目、API设置、缓存和生成工程不上传。
