# K10 集成

| DFR0523 | 连接 | 说明 |
|---|---|---|
| `D` | K10 已确认 PWM 引脚 | 500Hz PPM/舵机信号 |
| `+` | 独立稳压 5V/3A 正极 | 不接 K10 5V 或 GPIO |
| `-` | 独立电源负极并与 K10 GND 共地 | 缺少共地时禁止运行 |

官方停止脉宽为 1400–1600us。软件上电应先输出停止值，再初始化传感器和日志。自动浇花只使用单方向有限时运行；单次最长 3 秒，两次至少间隔 60 秒，并记录每日累计泵运行时间。

驱动板尺寸 27.4×28.7mm；水路和电子区应分离，管路需固定并设置接水防漏措施。
