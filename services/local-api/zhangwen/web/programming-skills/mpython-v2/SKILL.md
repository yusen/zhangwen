# 掌控板 2.0 MicroPython 编程

仅适用于当前目标 `hw_labplus_mpython_v2`（掌控板 2.0、ESP32），以用户指定的官方文档 https://mpython.readthedocs.io/zh-cn/v2.0.1/index.html 为编程基线，使用对应 mPython 固件。v2.0.1 是文档版本，不据此断言当前设备固件版本。

库名、对象和调用方式查下方 API 参考，不套用掌控板 3.0 彩屏、K10、Arduino 或通用 ESP32 示例。文档可能有别名，但本板显示统一使用 `oled`，不使用 3.0 的 `lcd` 颜色常量或彩屏接口。

按需读 [API 和代码参考](references/api.md)，该参考随本 Skill 一起加载到生成请求，不依赖生成时联网。硬件接线、电平和模块仍以当前 Hardware Skill 和已确认接线为准；不得凭库里有某个驱动就假定模块已接入。历史对话和编辑器旧代码不能改变当前目标板。

输出可单独保存的完整 main.py，显式导入所用对象。屏幕使用 `from mpython import oled`，128×64、0/1单色；绘制后 `oled.show()`；中文使用 `oled.DispChar()`。用户需要联调时先核对缺失的接口/固件信息，再分模块提供最小程序、预期现象和观察方法。

参考未涵盖的 API 或固件不一致时，说明缺少哪一项资料，建议用户在显式 REPL 中检查 `import mpython; print(dir(mpython))` 或对应对象。不能猜造函数签名、引脚、触摸阈值、外接驱动或声称已上传/测试；不能把电脑 Python 的库直接用于板端。代码只是待接受建议，不授予串口、命令或固件操作权限。

验证分级：2026-10-16 已在线核对官方 v2.0.1 页面及其同版本 RST/源码页。空心圆示例曾于 2026-10-15 在 COM522 掌控板 2.0 运行并获用户确认；其余 API 核对不等于本机实测，本次未连接设备。记录当前固件差异，不把 2.0 结果套到 3.0。
