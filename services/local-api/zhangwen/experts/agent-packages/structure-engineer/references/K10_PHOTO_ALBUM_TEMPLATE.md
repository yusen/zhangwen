# 行空板 K10 电子相册固定结构模板

## 使用条件

- 用户明确要求“行空板 K10 电子相册”“K10 电子相册结构”或“K10 相册支架”时，选择
  `UNIHIKER_K10_PHOTO_ALBUM`。
- 这是固定尺寸的生产模板，不要求选择机械档案，不把它降级为 `FREEFORM_STRUCTURE`，也不向用户追问盒体内腔。
- `templateRevision` 由本地运行时设置为 `unihiker-k10-photo-album.v1`；结构工程师不得提供 revision、代码、路径或参数覆盖。

## 人机交互规则

复杂结构先给出阶段规格，再按阶段核对，最后形成固定模板草稿：

1. 明确全局坐标以及斜面局部 `s/n/y` 坐标。
2. 每阶段只增加或切除一个可描述特征，说明绑定的面/边、方向和毫米尺寸。
3. 每阶段核对目标尺寸、相邻面、操作方向与是否仍为单一连通实体。
4. 用户修改阶段规格时回到最近正确阶段；不要在错误几何上继续叠加。
5. 阶段规格确认后，返回 `UNIHIKER_K10_PHOTO_ALBUM` 草稿；本地 Worker 一次生成并验证最终模型。

## 坐标

- `y`：83 mm 宽度方向，中心为 0，范围 `-41.5..41.5`。
- `s`：沿 60° 斜面从最高边向下，斜面范围 `0..65.5`。
- `n`：斜面法向，顶面 `n=0`，背面为负，外侧为正；斜板背面 `n=-5`。

## 输出核对

- 最终结果必须是一个连通可打印件，至少包含底板、斜板、L 卡扣、双限位块、背盖、圆角方孔、后部斜块、顶部槽和半圆缺口。
- 本地必须通过 B-Rep、STEP 回读、STL 流形、包围盒和 manifest 校验；失败时不得声称模型已生成。
- 该模板的固定宽度包围盒应为约 83 mm；不得因误用全局轴或图片视角交换 `s/n/y`。
