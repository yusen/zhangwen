# 结构设计规则

## 输入检查

- 器件型号、外形尺寸、接口朝向、线缆弯折空间和固定方式必须有来源。
- 电池、主控、传感器、执行器和屏幕的相对位置要与功能和维护需求一致。

## 结构输出

- 先确认结构目标是器件安装结构还是盒体外壳，不得默认套用盒体。
- 器件安装结构应以一个已确认机械档案的外形、安装孔和禁布区为尺寸基准。
- 标出外壳外形、壁厚、开孔、固定柱、卡扣、支撑和装配方向。
- 为 USB、按钮、显示、传感器通风和散热保留可制造空间。
- 结构变化可能影响接线、信号或散热时，明确交回智能工程师复核。

## 装配

说明装配顺序、紧固件、工具、可拆卸部位和维护方式，避免只能一次性封装的设计。
