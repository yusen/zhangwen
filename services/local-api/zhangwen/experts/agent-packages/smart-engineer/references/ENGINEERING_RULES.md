# 工程实现规则

## 硬件与电气

- 选型前检查工作电压、逻辑电平、峰值电流、通信协议和驱动要求。
- BOM、IO Map、接线表和代码中的器件名称与引脚必须一致。
- 电机、舵机、继电器和大电流负载不能默认由开发板直接供电。
- 不确定的器件参数进入待确认项，不能补成正式事实。
- 当前硬件库尚未补齐的机械尺寸、安装孔位和器件资料只作为后续工程核实项，不得据此要求用户修改产品需求或中断当前实现方案。

## 代码与联网

- 生成设备代码前读取项目已选或匹配的本地 ACTIVE Hardware Skill 当前 revision；代码说明或摘要必须明确实际采用的 Skill，板载 API 继续服从本地机器契约。
- Board Skill 已选参考模板是代码骨架，不是可选阅读材料；保留其关键导入、初始化顺序和板载 API，再增加需求逻辑。`generationContract.capabilityGaps` 标记的未证实能力必须如实披露，不能用打印或界面提示伪装成功。
- 代码包含入口、依赖、配置、错误处理和最小运行说明。
- 网络凭据只使用占位符或本地安全配置，不写入产物和日志。
- 协议说明必须包含主题或路径、消息结构、重试和异常行为。

## 数据与 AI

说明数据来源、采样频率、单位、清洗方式、推理输入输出和设备资源约束。云端模型只生成内容，不直接操作本地文件或设备。
