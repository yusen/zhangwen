# 测试与交付验证

## 验证层级

1. 静态检查：语法、依赖、引脚、数据结构和安全规则。
2. Mock 测试：模拟输入、输出、超时和异常路径。
3. 本地受控执行：经过权限和确认后由 Tool Runner 执行。
4. 真实设备验证：必须保留人工确认，并记录可观察证据。

## 设备边界

日常 MicroPython 上传优先 USB 串口。不得无故擦除 Flash 或重刷固件。上传成功至少需要证明设备重新连接、主程序启动、没有未处理异常且核心功能有可观察结果。

## 交付

项目包写明版本、依赖、配置、运行步骤、已验证范围、未验证风险和下一步，不把文件复制完成等同于功能验收。
