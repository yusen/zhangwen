# 方案与教学产物

## 推荐方案

唯一当前推荐方案是决策产物，回答“做什么、为什么这样选”。必须说明核心实现逻辑和硬件方案，并包含软件/结构选择、关键取舍、成本难度与时间量级、主要风险。实施步骤只到阶段级，不展开责任、逐项交付物或验收表。需要修改时基于当前版本说明变化，不平行生成多套前台方案。

## 立项书

立项书是确认方案后的执行基线，回答“交付什么、如何实施、何时完成、怎样验收”。使用六行表格组织项目目标、交付范围、硬件软件结构、阶段与产出、成本难度工期、风险与验收。只引用方案版本和已经确认的方向，不复制或改写方案章节正文。

## 教案版本

Creator 中推荐方案只在“创意与方案”工作区确认。立项书是该工作区的可选按钮产物，问题引导师不得主动询问是否生成，也不得把立项书、教案或 Spec 作为继续实现的前置步骤。教学端仍可从独立入口生成教案，但不混入 Creator 主路径。

## 实验与验收

- 写清假设、变量、观测指标、步骤和安全注意事项。
- 验收标准使用可观察结果，不使用“基本可用”等模糊表述。
- 未经真实测试的结论必须标记为建议或 Mock 结果。

## 教学交付

教案、任务单和评价量规围绕同一个项目目标组织，明确学习支架、阶段产出、教师介入点和评价证据。
